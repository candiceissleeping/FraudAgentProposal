# 實驗 3：模型「知道出事」的自述是真實記憶嗎（預先登錄，2026-11-08）

本文件在下載任何 AAER 原文、建立任何事實表、執行任何查核之前提交。

## 0. 目的
實驗 2（`results/mem_models/evaluation.md`）顯示：第八輪樣本上，只用「模型說知道出事」排序，AUC 就接近整體 AUC；扣掉這個旗標後只剩 0.54–0.63。
這個推論的前提是：模型說「知道」時，真的記得那件事。本實驗檢驗這個前提：把每一則「知道」自述的理由（`basis`），和 SEC 的公開紀錄比對。

## 3. 評分
**評分者**：每家公司一個隔離的 `claude -p --model claude-opus-5-5 --tools ""` session（同樣的 7 項無上網檢查），輸入該公司的事實表與該公司全部「知道」自述。
自述**不標示來自哪個模型**，以固定種子打亂順序並重新編號。評分者只回答下列四個欄位，總判定由程式依規則計算：

| 欄位 | 選項 | 定義 |
|---|---|---|
| issue | match / partial / mismatch / not_stated | 自述的問題類型與事實表相同／部分相同或較籠統但不衝突／不同／沒說問題類型 |
| consequence | correct / incorrect / not_stated | 自述的後果（重編、不可依賴、SEC 處分、延遲申報等）與事實表相符／不符／沒說 |
| contradiction | yes / no | 自述包含與事實表矛盾的事實（錯的期間、錯的問題、紀錄中沒有的事件） |
| record_exists | yes / no | 事實表中，在 2026-07-01 前是否有涵蓋該會計年度的公開問題紀錄（由事實表決定，評分者照抄） |

**總判定（程式計算）**
| 判定 | 規則 |
|---|---|
| 正確且具體 | record_exists = yes、issue ∈ {match, partial}、contradiction = no |
| 正確但籠統 | record_exists = yes、issue = not_stated、consequence = correct、contradiction = no |
| 無紀錄支持 | record_exists = no（自述無法被公開紀錄證實） |
| 錯誤 | 其餘（有矛盾、問題類型不同、後果不符） |

**人工抽查**：以固定種子抽 20% 的自述，由協調者在看到評分者結果**之前**依同一規則人工判定，報告兩者一致率。

## 4. 指標
- M1：第八輪問題公司的「知道」自述中，「正確（具體＋籠統）」的比例，分模型
- M2：其中「正確且具體」的比例，分模型
- M3：第八輪對照公司與時間外樣本的「知道」自述中，有紀錄支持的比例，分模型
- 人工抽查一致率

## 5. 判讀（事先寫下）
- M1 ≥ 80%（每個模型）→ 「知道」自述大多是真實記憶；實驗 2「區分力來自記得結果」的推論成立
- M1 < 60% → 自述不可靠，實驗 2 的分層不能解讀為記憶；要改寫結論
- 介於中間 → 如實報告，按公司說明哪些記得、哪些不對
- M3：對照公司或時間外樣本的「知道」如果多半無紀錄支持，代表模型會捏造「知道」；這可說明 Sonnet 對照組「知道」較多、區分力較低的原因
- 人工抽查一致率 < 80% → 評分不可靠，改以人工判定為主
