檢索日：2026-11-17。做法：先假設「沒人做過」不成立，去找已經做過的研究。
範圍與限制見第 5 節。所有文獻都只讀到摘要（arXiv API 或 Crossref 取回），沒有讀全文。

## 1. 結論
- **沒有找到**同時滿足下列四項的研究：(a) 結果變數是財報錯報或舞弊；(b) 事件在模型訓練截止之後（不可能記得結果）；(c) 依模型對公司的**事前了解**分組（不是依是否記得結果）；(d) 估計的是「給文件」相對「只給名稱」在各組內的增益。
- **但這個想法的幾個組成部分都有前例**，所以不能寫成「沒人研究過模型的先備知識如何影響文件的價值」。能主張的是上面四項的組合。
- 最接近的三篇：Efe 等 (2026)、Gao 等 (2025)、Park (2026)。Fang 等 (2026) 的全文需要讀（見第 4 節）。

## 3. 對題目的含意
1. 「上下文在模型不了解的實體上幫助較大」在事實問答上已是既有發現（2.3）。本題的新意不在這個原理，而在把它用於**預測尚未發生的結果**：模型的了解不是答案本身，而是事件前的公司狀況。
2. Havaldar 與 Santus (2026) 的方向相反，需要在論文中處理：事實問答與風險判斷是不同任務，但審稿人會問。
3. Efe 等 (2026) 已經提出「報告只給名稱的預測力」與「依辨識分層」，本題必須明確寫出多做了什麼：截止後事件、把「記得結果」與「事前了解」分開、年報而非逐字稿、足夠的不了解樣本。
4. Lehner 與 Lopez-Lira (2026) 顯示「凍結模型對公司的事前了解能預測截止後結果」在報酬上已有人做；題目 3 的新意因此縮窄為錯報標籤，以及與公開申報基準的比較。
