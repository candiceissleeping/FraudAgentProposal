# 第七輪基準方法 B：整份 10-K 直接交給 LLM 打風險分數（Claude agent 版）

> 評分者：每份 10-K 各開一個新的 Claude agent，看不到研究對話與標籤，檔名改為隨機順序的中性名稱（`llm_claude_agent_filename_map.json`），提示詞與預先登錄的 RISK_TASK 相同。gpt-5.5 版本尚未執行。

## 結果（14 對 14）

| 方法 | AUC | 95% CI | 組內勝 / 平 / 負 |
|---|---|---|---|
| **B LLM 風險分數（Claude agent）** | **0.90** | 0.73–1.00 | **13 / 0 / 1** |
| F Dechow | 0.67 | 0.44–0.89 | 7 / 0 / 6 |
| C 一致性（只用程式） | 0.57 | 0.36–0.78 | 8 / 1 / 5 |
| M Beneish | 0.48 | 0.23–0.74 | 4 / 0 / 6 |

## 辨識污染：這個 0.90 大部分不是方法本身的能力
- 28 家全部被認出（未遮蔽名稱）
- 模型說「知道後來有會計問題」：問題公司 **13/14**，對照公司 **0/14**
- 唯一一家模型**不知道**後來出事的問題公司是 Gentex，它只拿到 **7 分**，是 28 家中最低之一；組內唯一判錯的也是這一組（Gentex 7 vs Visteon 10）
- 只看模型「不知道後來出事」的 15 份（問題 1、對照 14），AUC 只有 0.04
- 結論：B 的高 AUC 幾乎完全可以用「模型記得哪些公司後來被 SEC 處分」解釋

## 但年報本身也有訊號
- 3 家對照公司模型不知道有問題，卻給了中高分：Welbilt 45、theMaven 38、TransAtlantic 27。理由都寫在年報裡（內控重大缺失、多次重編、關係人交易、數字不一致）
- 問題公司的高分理由多半也引用年報內容（例如 CPI Aero 的合約資產佔營收 135%、SAExploration 單一不具名客戶的大額應收帳款），且和 SEC 後來的認定方向一致
- 但無法分辨模型是「讀出」這些訊號，還是「因為知道結果才挑出」這些訊號

## 下一步
- 要得到乾淨的 B，必須遮蔽公司名稱，並選模型訓練資料之後才公開的案例；或用 gpt-5.5 版本比較兩個模型的辨識率
- 本輪仍以 F-score（0.67）作為不受辨識影響的最佳數字方法
