# 第九輪 b 結果：AAER 時間外案例 + 封閉式辨識

> 設計見 [`protocol.md`](protocol.md)（在建立任何 9b 卡片、執行任何 9b agent 前提交）；程式輸出見 [`evaluation.md`](evaluation.md)。
> 補做第九輪的兩個缺口：(1) 第九輪的標籤是 8-K 4.02，不是使用者原本要求的 **AAER**；(2) 第九輪沒有做封閉式（給候選名單）辨識。

## 一句話結論
- **AAER 標籤（目標一）：達成。** 2026-07 至 10 月（模型訓練截止後）發布、針對 10-K 發行人財報的 AAER 共 3 家。只給名稱問模型，**0/3 知道 SEC 會對它們採取執法**。評分 agent 0/6 知道後來有問題，開放式辨識 0/6。
- **分數（目標二）：3 對全部「問題公司 > 對照公司」**，但其中兩家的差距很小，分數本身也低（24 vs 18、22 vs 14）。只有 Latch 的年報本身有明顯紅旗（72 vs 30）。這與第八輪的發現一致：年報看不出來的問題，J0 不會給高分，這正是「讀出來」而不是「想起來」的特徵。
- **封閉式辨識：事實卡仍可被配對回公司（34/54）。** 但第九輪的結果都在截止後才公開，被配對到的 34 家，模型 0 家知道後來出事。**認得出公司 ≠ 知道結果。**

### 1.3 解讀
- **目標一**：三家的 AAER 都在模型訓練截止之後才發布，模型 0/3 知道。這是使用者原本定義的條件：「LLM 不知道這家公司未來會被列入 AAER」。
- **Latch 的注意事項**：模型不知道 AAER，但知道 Latch 在 2022 年宣布財報不可依賴（截止前已公開）。所以對 Latch 而言，「知道曾出問題」這一層沒有被排除。不過 J0 看不到名稱，0/6 認出公司，給 72 分的理由全部來自卡片：重編（SPAC 時期的權證重編）、IT 內控重大缺失、換會計師、SPAC 上市、應收成長快於營收、M-score 與 F-score 都超過門檻。
- **Travel + Leisure 與 The Bancorp**：J0 雖然排在對照之前，但分數只有 22–24，實務上不會被標記為高風險。原因是它們的問題（以撤銷貸款壓低呆帳率、查核未完成就申報）在年報裡看不出來。這與第八輪 SAExploration、GTT 的情況相同。**J0 抓不到年報裡沒有的東西**，這是限制，也是「沒有在用記憶」的證據。
- 3 對不能估 AUC。這部分是第九輪（4.02，27 對，AUC 0.77）的補充，證明換成 AAER 標籤時，「模型不知道結果」這個條件仍然成立。

## 2. 9b-B：第九輪封閉式辨識

| 檢驗 | 結果 |
|---|---|
| 給 54 家名單，把 54 張 J0 卡配對回公司 | **34/54 正確**（只靠產業大類隨機猜期望 7.0，p < 10⁻¹⁹） |
| 問題組／對照組 | 14/27、20/27 |
| 配對正確的 34 家中，MEM 說知道後來出事 | **0** |

- 和第八輪（26/28）一樣：**只要給候選名單，事實卡就能被配對回公司**。卡片上的產業、規模比率和少見事實（SPAC、單一客戶比例、銀行）就是指紋。
- 但第九輪的設計不依賴「認不出來」：結果在截止之後才公開，認出公司也無法得知結果。被配對正確的 34 家，模型沒有一家知道後來出事。
- 這也解釋了第八輪為什麼必須做時間外測試：截止前的樣本，「認得出」就等於可能「想得起結果」；截止後的樣本，兩者被切開了。

## 3. 對兩個目標的最終判定（第九輪 + 9b 合併）

**目標一：讓 LLM 不知道是哪家公司、不知道後來有 AAER**

| 層次 | 證據 | 判定 |
|---|---|---|
| 不知道後來有 AAER | AAER 0/3（9b）；4.02 結果 0/27（K1）；評分者 0/54 + 0/6 | **達成**（由時間設計保證，逐家確認） |
| 評分者不知道是哪家公司 | 開放式辨識 0/54 + 0/6；評分者 0/60 有猜名稱 | **達成** |
| 給名單時也配對不回去 | 封閉式 34/54 | **未達成**，但在時間外設計下不影響結果記憶 |

**目標二：分數來自推理還是記憶 → 來自推理（年報內容）**

| 證據 | 結果 |
|---|---|
| 結果不可能被記得的樣本上仍有區分力 | 4.02：AUC 0.77（0.64–0.89）；AAER：3/3 組內正確 |
| 加名稱不再提升 | 記憶效應 +3.6（CI 含 0）；第八輪時間內是 +16.6 |
| 改動內容，分數跟著動 | 12/12（中位數 34 分） |
| 年報看不出的問題拿低分 | T+L、Bancorp 只有 22–24 分 |

必須一起報告的限制：
- J0 的區分力大部分來自「公司是否處在高風險狀態」，與名稱先驗高度相關（ρ = 0.72）；扣除後的增量 AUC 0.65（0.50–0.80）
- AAER 案例只有 3 對；4.02 不等於舞弊
