# 第九輪 b：AAER 時間外驗證 + 封閉式辨識（預先登錄）

本文件在建立任何 9b 事實卡、執行任何 9b agent 之前提交。已知的只有：AAER 清單（公司名稱、日期）與三家公司 10-K 的申報編號。

## 0. 為什麼要補做
第九輪的標籤是 8-K Item 4.02，不是使用者原本要求的 **AAER**；也沒有做封閉式（給候選名單）辨識。本輪補這兩件事：
1. **9b-A：AAER 標籤**。用模型訓練截止（2026-06）之後才發布的 AAER，直接檢驗「模型不知道這家公司未來會被列入 AAER」，以及在這些公司上分數是否仍由內容驅動
2. **9b-B：封閉式辨識**。給第九輪 54 家公司名單，要求把 54 張事實卡配對回公司

## 2. 9b-A 檢驗
| 代號 | 檢驗 | 標準 |
|---|---|---|
| A1 | **AAER 記憶探針**：只給名稱與年度，分別問 (a) 是否知道該期間有會計問題或重編；(b) 是否知道 SEC 對該公司或其主管就該期間財報採取執法行動（AAER／cease-and-desist／起訴） | (b) 問題組 **0/3** 知道 |
| A2 | J0 評分者自述知道後來有問題；開放式辨識 | 0/6；描述性 |
| A3 | J0 組內比較：問題公司分數 > 對照 | 描述性（n = 3，隨機全對機率 1/8，不做推論） |
| A4 | J1（加名稱）− J0 | 描述性 |

判讀：
- A1(b) = 0/3 → 對 AAER 標籤而言，目標一由設計成立並逐家確認
- A1(a) 若為「知道」（例如截止前已公開的重編），如實報告：模型知道「曾有問題」，但不知道「將被列入 AAER」
- 3 對無法估計 AUC；本部分是第九輪（4.02，27 對）的補充，不取代其結論

## 3. 9b-B 封閉式辨識（第九輪 54 張 J0 卡）
- 一個 agent，拿到第九輪全部 54 家名稱（不分組、依字母排序）與 54 張 J0 卡，用 `data/round8/probe_closed_prompt.md` 相同指示（54 取代 28），把每張卡配對到一家公司
- 報告：配對正確數、只靠產業大類隨機猜的期望值與單尾 p 值
- **判讀（預先寫下）**：第九輪的結果在模型訓練截止之後才公開，所以即使配對正確率高，也不影響「模型不知道結果」；它只回答「事實卡是否仍帶有指紋」。被配對正確的公司，用 K1／A1 的結果確認模型不知道其結果
