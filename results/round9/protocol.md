# 第九輪：時間外驗證（預先登錄）

本文件在選出任何案例、建立任何事實卡、執行任何 agent 之前提交（8-K 掃描進行中，尚未看到任何 4.02 名單）。

## 0. 目的
第八輪證明：拿掉公司名稱後，評分 agent 認不出公司、也不知道結果，分數也跟著內容走；但只要給候選名單，事實卡仍可被配對回公司，所以無法**保證**分數沒有用到記憶。
本輪用**模型訓練資料截止（2026-06）之後才公開問題的公司**。模型就算認出公司，也不可能知道後來出事，因此：
- 目標一：由設計保證（並用 MEM 探針逐家確認）
- 目標二：如果分數仍能區分問題公司與對照公司，這個能力只可能來自年報內容

## 1. 樣本
### 1.1 問題組
- 事件：2026-07-01 至 2026-10-31 申報的 8-K（含 8-K/A），表頭 ITEMS 含 **4.02**（先前發布的財報不可再依賴）
- 每家公司取窗口內第一筆 4.02
- 排除：
  - SIC 6770（空白支票／SPAC 殼公司）：多為權證會計，與營運舞弊無關
  - 沒有原始 10-K 的申報人（外國發行人、基金、ABS）
  - 4.02 申報日之前沒有原始 10-K，或 Y0 10-K 沒有 XBRL
- Y0：4.02 申報日之前最後一份**原始** 10-K（不用 10-K/A）；Y-1：再前一份原始 10-K
- 若合格案例超過 30 家，以固定種子（20261102）隨機抽 30 家
- 標籤是「4.02 事件」，不是 AAER（AAER 通常落後數年）。4.02 包含錯誤，不全是舞弊

### 1.2 對照組（程式自動選，每家問題公司 1 家）
- 候選池：同一窗口內有申報 8-K、但窗口內**沒有任何 4.02** 的公司（表頭提供 SIC）
- 同產業：4 位數 SIC 相同；候選少於 3 家放寬到 3 位、再放寬到 2 位
- 規模：XBRL frames 中，與問題公司 Y0 期末同一季的總資產，取 |ln(對照 ÷ 問題)| 最小者
- 必須有期末日在問題公司 Y0 期末 ±92 天內的原始 10-K（含 XBRL）與前一份原始 10-K；不符合就取下一家
- 每家對照只用一次

### 1.3 Y0 是否涵蓋在不可依賴期間（次要分析用）
- 程式讀取 4.02 8-K 主文件；若文中出現 Y0 的會計年度（例如「December 31, 2025」「fiscal 2025」「year ended … 2025」），標記 covers_y0 = 1
- 主分析用全部；次要分析只用 covers_y0 = 1 的配對

## 2. 流程（與第八輪完全相同，程式沿用 `round8.py`）
- 程式遮蔽 → 抽取 agent（同一份 `data/round8/extract_prompt.md`、28 個欄位）→ 引文驗證 → 事實卡（同 J0 格式：產業大類 + 欄位 + 2 位小數比率）→ 判斷 agent（同一份 `judge_prompt.md`）
- 代碼 R9-xx（隨機），不帶 T/C

## 3. 預先登錄的檢驗
| 代號 | 檢驗 | 標準 |
|---|---|---|
| K1 | **MEM 探針**：只給名稱與年度，問是否知道後來有會計問題、重編或 SEC 執法 | 問題組「知道」的比例 ≤ 20%；知道的公司在敏感度分析中排除 |
| K2 | 評分 agent 自述知道後來有問題（J0） | ≤ 1 家 |
| H1 | **J0 在時間外樣本的 AUC > 0.5** | 單尾 bootstrap，95% CI 下界 > 0.5 |
| H2 | 時間外 J0 AUC 與第八輪（時間內）J0 AUC 0.67 的差 | 描述性；差 < 0.10 表示第八輪的估計沒有被記憶明顯灌水 |
| H3 | **加上真實名稱（J1）在時間外樣本不應提高區分力** | J1 − J0 的「記憶效應指數」（問題組平均差 − 對照組平均差）的 95% CI 包含 0；對照：第八輪為 +16.6 |
| H4 | 內容擾動（同第八輪 G2b，各 6 張） | ≥ 10/12 方向正確 |
| 參考 | F-score、M-score 的 AUC（程式計算） | 描述性 |

判讀：
- K1、K2、H3 通過 → 目標一成立（模型不知道結果，名稱不再帶來優勢）
- 再加上 H1、H4 通過 → 目標二成立：分數有區分力，而且這個區分力不可能來自記憶
- H1 未通過 → 事實卡方法在乾淨條件下沒有區分力；第八輪的 0.67 可能有記憶成分（或樣本太小），如實報告

## 4. 已知限制
- 4.02 是重編事件，不等於舞弊；本輪驗證的是「讀年報預測財報不可依賴」的能力
- 模型的訓練截止日不精確；K1 逐家確認
- 部分 4.02 只涉及 Y0 之後的季報（Y0 年報本身可能正確），所以有 covers_y0 次要分析
- 樣本仍小（≤ 30 對）
