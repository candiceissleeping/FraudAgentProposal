# 第九輪結果：模型認不出的小公司（3 對 3）

> 每份年報各兩個等級（L0′ 未遮蔽、L3c 遮蔽），每次一個新的 Claude agent。原始分數：`scores.csv`。

|---|---|---|---|---|---|---|

- AUC：L0′ 0.94、L3c 0.83

## 2. 「認得公司但不知道後來出事」的兩家問題公司
**Netcapital（SEC 訴訟晚於模型訓練截止日）**
- 兩個等級都給高分（78、62），對照公司都是 12
- 理由直接對準 SEC 後來指控的機制：大部分營收是「顧問服務」收取新創公司的股權（L0′：FY2024 的 70%；L3c：同一比例），以這些公司自己在本公司平台上的募資價格估值，而且多個客戶的交易金額幾乎一樣（L3c：數家各 4,743,352 單位 × $1.35），像是設計出來的金額；股權資產佔總資產約 61%、幾乎未減損
- 這是本研究目前**最乾淨的「讀出」案例**：模型不知道後來的訴訟，但從年報讀出了正確的問題

**C-Bond（2024 年處分，但模型不知道）**
- 25 分，與對照公司相當，沒有讀出問題
- 實際錯報是 10 萬美元左右的未出貨訂單（佔 2020 年營收 >15%），金額很小；agent 有注意到應收帳款存在性是查核關鍵事項，但沒有把它當成重大警訊

**Kubient（知道後來出事）**：85 / 72 分。但理由中也有年報本身的強證據：KAI 營收（$1,300,338）與同年資本化的「取得第三方資料」（$1,300,336）幾乎相等，像是對敲。無法分開讀出與記憶

## 3. 本輪遮蔽的已知問題
agent 指出 L3c 中部分權益變動表股數、MD&A 與報表的數字不一致，有些應是遮蔽縮放造成（例如 Netcapital 的 shares to be issued 金額），有些是原始申報本身的錯誤；多數 agent 未把它們當成主要理由

## 4. 結論
1. **小公司在有名稱時一定被認出，遮蔽後也仍被認出**；但「知道後來出事」從中大型公司的 5/5 降到 1/3。對小公司，主要的污染來源（知道結果）大致被切斷
2. 在「不知道後來出事」的兩家問題公司中：Netcapital 被正確讀出（高分、理由對準實際手法），C-Bond 沒有（低分）。模型能從年報讀出**規模大、結構明顯**的舞弊（佔營收七成的自訂價股權收入），讀不出**金額小、單筆**的錯報
3. 樣本只有 3 對，只能看方向。下一步：用同樣方法擴大到更多小公司（尤其是 SEC 行動晚於模型截止日的案例），並在「不知道後來出事」的子樣本上計算 AUC
