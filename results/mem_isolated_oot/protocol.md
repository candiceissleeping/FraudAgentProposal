# 時間外樣本的隔離 MEM（預先登錄，2026-11-07）

本文件在執行任何本輪 Claude session 之前提交。

## 0. 目的
第八輪 MEM（只給名稱與會計年度）在隔離環境 5 次重跑 AUC 0.86–0.89（平均分數 0.88）。「只靠記憶」可能有兩種來源：
- (a) 記得結果：模型記得這家公司後來出事
- (b) 公司類型先驗：模型不知道結果，但從名稱知道「這是哪類公司」

本輪在**結果發生在模型訓練截止（2026-06）之後**的樣本上，用與第八輪隔離重跑**完全相同**的環境、提示與流程執行 MEM。
模型不可能記得這些結果，所以得到的 AUC 只能來自 (b)，作為「不知道結果時」的基準。

## 1. 樣本（第九輪的 27 對，不新增、不排除）
- 問題組（T）：2026-07-01 至 2026-10-31 申報 8-K Item 4.02（先前財報不可再依賴）的 27 家公司；排除 SPAC 殼公司、無原始 10-K 者（第九輪 `results/round9/protocol.md` §1.1）
- 對照組（C）：程式選出的同產業、同規模、窗口內沒有 4.02 的公司，每家問題公司 1 家（同上 §1.2）
- 會計年度：各公司 Y0（4.02 之前最後一份原始 10-K）的期末日，與第九輪相同
- 來源：`origin/claude/dreamy-volta-i6oimk` 的 `results/round9/pairs.json`
- 標籤是「4.02 事件」，不是 AAER；4.02 包含錯誤，不全是舞弊
- 第九輪 b 的截止後 AAER 2 對不納入（保持與第九輪 MEM 同一樣本，以便比較）

## 2. 輸入
- `data/mem_isolated_oot/input_round9.txt`：54 家，每行「名稱 — fiscal year ended YYYY-MM-DD」
- 名稱只統一大小寫與標點（EDGAR 全大寫改為公司寫法、拿掉 `/DE/`、Inc／Corp／Ltd 加句點），不改內容。
  第九輪原始名單全大寫的名稱對照組 7 家、問題組 4 家，屬於可能的格式洩漏，故統一
- 每次執行用不同種子打亂順序（種子 20261108–20261112）
- 提示：`data/mem_isolated_oot/prompt.md`，與第八輪隔離重跑的 `data/mem_isolated/prompt.md` 只差公司數（28 → 54）

## 3. 環境與流程（與第八輪隔離重跑相同）
- `claude -p --model claude-opus-5-5 --tools "" --strict-mcp-config --setting-sources "" --no-session-persistence`，每次在新的空目錄
- 先跑 canary（無工具時必須答不出截止後的台股收盤、7 項全過；開放搜尋時必須被偵測）
- 5 次執行；每次都必須通過 7 項無上網檢查，否則不使用
- 原始紀錄、回答、輸入清單 commit 之後才讀標籤（`key.tsv`）計算；`evaluate` 會檢查這一點

## 4. 預先登錄的檢驗
| 代號 | 檢驗 | 標準／用途 |
|---|---|---|
| O1 | 5 次全部通過 7 項無上網檢查 | 必要條件 |
| O2 | 問題組「知道後來出事」 | 預期 ≤ 2/27（每次）；超過表示有截止前已公開的線索，該配對在敏感度分析中排除 |
| O3 | AUC（5 次各自、5 次平均分數）與 bootstrap 95% CI | 主要結果：「不知道結果」時名稱能做到的區分力 |
| O4 | 與第八輪隔離重跑（平均分數 AUC 0.88）比較 | 描述性；兩個樣本組成不同（小型 4.02 公司 vs AAER 公司），差距不能全部歸給記憶 |
| O5 | 與第九輪原始 MEM（AUC 0.71，0/54 知道）比較：AUC 與 Spearman ρ | 描述性；檢查隔離環境與格式統一是否改變結果 |
| O6 | 5 次之間的 Spearman ρ | 描述性；穩定度 |

## 5. 判讀（事先寫下）
- O2 通過且 O3 的 AUC 明顯高於 0.5 → 名稱本身帶有「公司類型先驗」，第八輪 0.88 有一部分可能來自這個先驗，需要實驗 2（知道／不知道分層）才能拆開
- O2 通過且 O3 的 AUC 接近 0.5 → 在不知道結果時，名稱幾乎沒有區分力，支持第八輪 0.88 主要來自「記得結果」
- O2 不通過 → 如實報告哪些公司被說知道，並做排除後的敏感度分析
