## B. 提案的新方法

### 1. 全市場 XBRL + AAER 資料庫（基礎）
- SEC 全部 AAER（追溯到 2010）對應 CIK；2010 年後所有 10-K 的 XBRL 數字（「當時申報的版本」）
- 預計數萬筆公司年度、約 1% 為 AAER 案例；依時間切開訓練（例 2010–2016）與測試（2019 以後）
- 基準：F-score、M-score、XGBoost

### 2. 悄悄修改偵測（little r）
- 比對今年年報中的「去年數字」與去年原本申報的數字
- 程式檢查是否有說明（restated、reclassified、ASU 採用、8-K Item 4.02）；沒有說明的修改列為可疑
- 修改分數：科目重要性 × 幅度 × 是否有說明
- 第七輪：問題公司 3/14、對照 2/14 有修改；LLM 漏掉的 Gentex 被抓到

### 3. 同業偏離
- XBRL frames 取同產業同年度所有公司，計算比率的偏離程度（收縮共變異數的 Mahalanobis 距離）

### 4. 科目先驗
- 統計 700 份 AAER 原文中最常被做假的科目（營收、應收、存貨、準備金、資本化…），給這些科目的異常較高權重

### 5. LLM 抽事實，不下判斷
- 預先定義約 30 個可驗證的事實欄位（見下表），LLM 只回答「年報寫了什麼」，每個答案附逐字引文與位置
- 程式驗證：引文必須在原文找得到；數字型答案與 XBRL 交叉核對；兩次抽取不一致時標為未知
- 輸入遮蔽名稱並把所有金額乘上同一個隨機係數；從記憶補出、原文沒有的事實會因引文驗證失敗被剔除
- 抽出的事實當作特徵，權重由模型在訓練年度學習，不由 LLM 決定
- 能用結構化資料取得的（審計師名稱、ICFR 證明旗標等 XBRL dei 標籤）不交給 LLM

| 類別 | 事實欄位（例） |
|---|---|
| 內控與審計 | 重大缺失（有/無、領域、是否改善）；會計師兩年內更換；繼續經營疑慮；關鍵查核事項主題 |
| 重編與修正 | 前期數字是否修正、原因；季報重編 |
| 營收認列 | 通路／經銷商銷售與退貨權；附帶協議；完工比例認列占比；政策變更；第四季營收占比 |
| 關係人 | 關係人營收／採購金額；董事長或其關係企業交易 |
| 集中度 | 最大客戶占營收比；最大客戶占應收比 |
| 管理層 | CEO／CFO 更換；代理 CFO；兼任（CFO 兼法務長等） |
| 法律監理 | SEC 調查或傳票；集體訴訟；司法部調查 |
| 壓力與誘因 | 債務契約豁免或修改；獎酬綁營收／EPS；當年或隔年籌資 |
| 估計判斷 | 市值低於帳面但未減損商譽；準備金下降而毛利上升；非 GAAP 調整幅度 |

### 6. 多 agent 證據辯論融合（參考 FraudDebate-Agent、AuditAgent）
- 數字 agent（1–4 的分數）、文字 agent（5 的事實）、同業 agent，加上辯論仲裁者；每個主張必須引用證據
- 輸出依 AS 2401 分類的報告（壓力／機會／合理化）
- 只對排名前段公司執行，控制 LLM 成本

### 7. 防記憶污染評估（每個 LLM 方法都要過）
| 關卡 | 做法 |
|---|---|
| 遮蔽 | 公司、人名、地名、年份遮蔽 |
| 數字縮放 | 所有金額乘同一隨機係數（比率不變） |
| 辨識探針 | 另外問「這是哪家公司」，依認出與否分組報告 |
| 時間外測試 | 只用模型訓練截止後才公開的 AAER 或 8-K Item 4.02（第九輪已執行） |
