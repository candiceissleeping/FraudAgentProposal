# 不同模型的隔離 MEM（預先登錄，2026-11-07）

本文件在執行任何 Sonnet 5.5／Haiku 5.5 的評分 session、以及計算任何「知道／不知道」分層數字之前提交。
（執行前只做過一次可用性測試：兩個模型各回覆一個 "OK"，7 項檢查全過，未涉及任何公司。）

## 0. 目的
檢驗 MEM 分數是否跟著「模型記得多少」變化。
- 如果第八輪 MEM 的 0.88 主要來自**記得結果**：記得越少的模型，第八輪樣本的 AUC 越低；時間外樣本上各模型都不可能記得，AUC 應相近
- 如果主要來自**公司類型先驗**：各模型在第八輪樣本上的 AUC 相近，與記得多少無關

## 3. 環境與流程（與前兩輪相同）
1. 每個模型先跑 canary：無工具時必須 7 項全過並答不出截止後的台股收盤；開放 WebSearch 時必須被偵測
2. 每個模型 × 每份樣本 5 次，`claude -p --tools "" --strict-mcp-config --setting-sources "" --no-session-persistence`，每次新的空目錄
3. **回答不完整**（無法解析、id 不是剛好 1…N、缺欄位或分數不在 0–100）：用同一份名單重跑一次；舊紀錄保留為 `run{k}_incomplete1.jsonl`。第二次仍不完整就記為失敗並報告
4. 每次都必須通過 7 項無上網檢查，而且實際服務的模型必須等於指定的模型；否則不使用
5. 原始紀錄、回答、名單 commit 之後才讀標籤；`experiment/mem_models.py compare` 會檢查這一點

輸出：`results/mem_models/{sonnet-5-5,haiku-5-5}/{round8,oot}/`。

## 4. 主要指標（每個模型 × 每份樣本）
- 5 次平均分數的 AUC（bootstrap 95% CI）、5 次各自的 AUC 範圍、組內勝負
- 問題組、對照組「知道後來出事」的次數範圍
- 與 Opus 平均分數的 Spearman ρ
- **記憶增量 Δ** = 第八輪平均分數 AUC − 時間外平均分數 AUC

## 5. 判讀（事先寫下）
| 結果 | 支持 |
|---|---|
| 第八輪 AUC 的高低順序與「第八輪問題組知道出事」比例的順序一致；Δ 隨知道比例變大；時間外各模型 AUC 相近、知道比例 ≈ 0 | 0.88 主要來自記得結果 |
| 第八輪各模型 AUC 相近，與知道比例無關；Δ 相近 | 0.88 主要來自公司類型先驗 |

- 時間外樣本上，任何「知道出事」都必定是錯誤自述，其比例視為該模型「捏造知道」的基準；問題組超過 2/27 時在報告中標示
- 只有 3 個模型、第八輪只有 14 對，CI 很寬：只看方向，不做顯著性檢定

## 6. 「知道／不知道」分層（實驗 2，同一批資料，不另外執行）
對每個模型 × 每份樣本：
1. **只用「知道」旗標的 AUC**：每次把「知道」當 1、「不知道」當 0 算 AUC，取 5 次平均
2. **殘差 AUC**：每次把分數減去該次同一組（知道／不知道）的平均分數，再算 AUC，取 5 次平均
3. **「不知道」子集 AUC**：5 次合併（公司 × 次數為單位），只比較說「不知道」的問題公司與說「不知道」的對照公司
4. 問題／對照 × 知道／不知道 四格的中位數分數與個數

判讀：
- 第八輪樣本上，若殘差 AUC 與「不知道」子集 AUC 接近 0.5，而「知道」旗標 AUC 接近整體 AUC → 該模型的區分力幾乎全部來自自述的記憶
- 若殘差 AUC 明顯高於 0.5（例如與時間外樣本的 AUC 相當）→ 除了記憶之外還有公司類型先驗
- 「知道」是模型自述；它是否為真實記憶（與 AAER 內容相符）由實驗 3 另外檢驗，本輪不做
