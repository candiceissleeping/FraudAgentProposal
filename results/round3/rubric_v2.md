# 第三輪評分規則 v2（預先登錄）

本檔與抽樣程式、候選名單在**抽樣與閱讀資料包之前**一起提交；提交時間即登錄時間。

## 與 v1 的差異
- A 新增「內部調查」15 分、「可能需要重編的預警」5 分
- B 新增「家族 / 創辦人 / 控制股東實質控制」5 分
- 新增第二段「整體判斷」分數與論點

## 輸入
`results/round3/packets/Rxx.md`：
- 公司名、人名、子公司、品牌、地名等專有名詞 → `[COMPANY]` / `[NAME]`
- 年份改為相對年份（Y0 = 該 10-K 的會計年度，Y-1 = 前一年）
- 固定內容：Item 9A、Item 9、Item 3 開頭 + 17 個固定查詢（每項最多 2 段）

## 第一段：規則計分（0–100，每一分須引用資料包原文）

| 面向 | 項目 | 分數 |
|---|---|---|
| A. 財報可信度（上限 40） | 實質重編已發布數字（不含拆股、合併追溯、新準則等機械調整） | 15 |
| | 當期或前一年度內控重大缺失 | 15 |
| | **稽核委員會 / 特別委員會 / 外部律師對會計、營收或主管行為的內部調查** | 15 |
| | 會計師辭任 / 解任且有意見不合或可報告事件 | 10 |
| | 持續經營疑慮（實際存在，非假設性風險因素） | 15 |
| | **可能需要重編、SEC 可能不同意會計處理等預警** | 5 |
| B. 關係人與治理（上限 25） | 對董事 / 主管 / 其家族的借款、擔保或共同借款 | 15 |
| | 與內部人控制實體的重大交易 | 10 |
| | 目的不明的未合併實體 / VIE 且公司提供擔保或資金 | 10 |
| | **家族 / 創辦人 / 控制股東實質控制（雙重股權、超級投票權、家族持股控制）** | 5 |
| C. 盈餘品質（上限 20） | 營收或損益高度依賴判斷性估計（Level 3、mark-to-model、通路庫存、交換 / IRU、備抵） | 10 |
| | 有利於盈餘的會計政策或估計變更 | 5 |
| | 成長主要來自漲價或併購，且強調非 GAAP 指標 | 5 |
| D. 法律 / 監管（上限 15） | 針對公司行為的政府調查 / 傳票 | 10 |
| | 證券詐欺集體訴訟 | 5 |
| | 僅有產品 / 反壟斷 / 勞資 / 合約訴訟 | 3 |
| E. 財務壓力（上限 10） | 違反契約條款 / 豁免、信評調降、流動性警告（實際發生） | 10 |

## 第二段：整體判斷（0–100）
- 讀完整份資料包後給一個整體風險分數，並寫 ≤150 字論點
- 論點**只能引用資料包內的原文**，不得使用資料包以外的知識
- 若認為自己認出公司，必須在 `recognized_as` 欄填寫猜測；認不出填 `no`

## 程序
1. `python -m experiment.edgar_risk.round3 draw`：程式驗證候選名單、隨機抽 5 組、產生資料包與**關鍵字分數**（以資料包編號記錄）
2. 提交資料包與關鍵字分數 → 評分者才開始閱讀
3. 寫入 `results/round3/scores.csv`（規則分數、整體分數、猜測）與 `scores.md`（理由）並提交
4. 提交後才執行 `python -m experiment.edgar_risk.round3 unblind`，揭盲後不得修改分數

## 已知限制
- 評分者知道候選名單（30 家），但不知道抽中哪 10 家
- 產業性質仍會從內容透露（例如「有線電視」「核桃」），無法完全遮蔽
