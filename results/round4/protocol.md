# 第四輪實驗流程（預先登錄）

本檔與候選名單 `config/round4_pool.json`、程式在**產生資料包與閱讀之前**提交。

## 與第三輪的差異
| 項目 | 第三輪 | 第四輪 |
|---|---|---|
| 候選名單 | 15 組，每產業 1 組 | **39 組，11 個產業，每產業 ≥3 組** |
| 樣本 | 隨機抽 5 組 | **全部有效配對**（目標 ≥30 組） |
| 遮蔽 | 名稱、人名、地名、年份 | 再加 **網址、電子郵件網域**；資料包標題不再被遮 |
| 評分規則 | v2 | **沿用 v2，不修改**（`results/round3/rubric_v2.md`） |

## 盲性設計
- 不再抽樣；盲性來自「每個產業至少 3 組配對」：看產業內容只能縮小到 ≥6 家公司，其中一半是問題公司。
- 資料包隨機編號 Q01…，對照表封存在 `data/round4/_key.json`（不進 git）。
- 每份資料包必須填寫 `recognized_as`（猜測或 `no`），揭盲後計算猜中率。

## 程序
1. `python -m experiment.edgar_risk.round3 draw --round 4`：驗證候選名單（剔除空檔或公司代碼錯誤），產生資料包與**關鍵字分數**
2. 提交資料包與關鍵字分數 → 才開始閱讀
3. 寫入 `results/round4/scores.csv`、`scores.md` 並提交
4. 提交後才執行 `python -m experiment.edgar_risk.round3 unblind --round 4`

## 主要指標
- 關鍵字 AUC（無評分者偏誤）及 bootstrap 95% 信賴區間
- 規則 v2、整體判斷的 AUC
- 辨識猜中率；若猜中率高，人工分數只作參考
