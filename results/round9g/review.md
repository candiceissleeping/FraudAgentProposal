# 第九輪 g 結果：時間外樣本上「整份 10-K 直接評分」

> 設計見 [`protocol.md`](protocol.md)（在下載任何未遮蔽 10-K、執行任何評分 agent 前提交）；程式輸出見 [`evaluation.md`](evaluation.md)。

## 一句話結論
在模型不可能記得結果的 27 對 8-K 4.02 樣本上，**整份未遮蔽 10-K 直接給 LLM 評分，AUC 0.76（0.62–0.88），與事實卡 0.77 幾乎相同**（差 −0.02，配對 bootstrap 95% CI −0.12 至 +0.09）。事實卡在擋住記憶的同時，沒有可偵測的資訊損失。

## 2. 怎麼解讀
1. **事實卡幾乎沒有損失資訊。** 給模型完整、未遮蔽的年報，在結果不可能被記得的條件下，也只做到 0.76，和事實卡 0.77 相同。資訊瓶頸擋住了記憶與辨識，代價測不出來。
2. **完整年報也沒有勝過「公司類型先驗」多少。** 扣除只給名稱的 MEM 後，RAW 和 J0 的殘差都約 0.65。也就是說，在這個樣本上，讀年報（不論完整或事實卡）的額外貢獻大致相同，且都不大。
3. **RAW 的分數更貼近名稱先驗（ρ 0.88 vs 0.72）。** 模型認得公司時，分數更像「這是哪類公司」的判斷；事實卡讓分數較少跟著公司類型走，但區分力不變。
4. **與第七輪的對比：** 同樣是「整份 10-K 直接評分」，第七輪（模型記得結果的 AAER 樣本）0.90、14 家問題公司中 13 家被說出後來出事；本輪（模型不可能記得）0.76、0/27。差距與名稱開關（第九輪 d：+0.15）方向一致。

## 3. 執行偏差（如實記錄）
- 提示要求「從頭到尾分段讀完」。多數 agent 讀完全文，但部分 agent 對風險因素、高管薪酬等段落改用關鍵字搜尋或略讀（G-02、G-13、G-16、G-18、G-22、G-35、G-37、G-40、G-49 等自述）。
- 兩個 agent（G-09、G-46）列出了評分輸出資料夾的檔名，但自述沒有開啟任何檔案。G-09 列出時資料夾為空。
- 以上偏差都不涉及讀取標籤或其他公司的資料，不改變判讀。
