# 第九輪 g：時間外樣本上「整份 10-K 直接評分」（預先登錄）

本文件在下載任何未遮蔽 10-K、執行任何評分 agent 之前提交。

## 0. 目的
第九輪（時間外 8-K 4.02 樣本，27 對）只做了事實卡（J0）、事實卡加名稱（J1）與只給名稱（MEM），**沒有做「整份 10-K 直接交給 LLM」**。第七輪做過這個條件（方法 B，AUC 0.90），但當時樣本的結果模型都記得，所以它只能代表「記憶污染的上限」。

在第九輪樣本上，結果發生在模型訓練截止（2026-06）之後，模型不可能記得。此時整份 10-K 是一個乾淨的對照，回答兩個問題：
1. 給 LLM 完整、未遮蔽的年報，且結果不可能被記得時，它能區分到什麼程度？
2. 事實卡（資訊瓶頸）相對於完整年報損失了多少區分力？

## 1. 樣本
第九輪的 27 對、54 份 Y0 原始 10-K，與第九輪完全相同（`results/round9/pairs.json`）。不新增、不排除任何公司。

## 2. 條件 RAW
- 輸入：Y0 原始 10-K 的主文件與 EX-13，轉為純文字，**不遮蔽**任何內容（與第七輪方法 B 的 `round7_llm.build` 相同處理）。
- 檔名：新的隨機代碼 `G-xx`（種子 20261105），與第九輪的 `R9-xx` 代碼無關，不帶問題／對照標記。
- 評分：每份 10-K 一個新的評分 agent，只能讀提示檔與該份 10-K（分段讀完）。提示詞沿用第七輪的 `RISK_TASK`，存於 `data/round9g/raw_prompt.md`。
- 輸出：`risk_score`（0–100）、`main_reasons`、`recognised_company`、`company_name_guess`、`knows_later_problems`。
- 模型：與第九輪相同的評分模型。

## 3. 預先登錄的檢驗
| 代號 | 檢驗 | 標準 / 用途 |
|---|---|---|
| G1 | RAW 的 AUC 與 bootstrap 95% CI | 描述性；CI 下界 > 0.5 表示有區分力 |
| G2 | RAW − J0 的 AUC 差（同一批 54 份，配對 bootstrap 95% CI） | CI 包含 0 → 事實卡沒有可偵測的資訊損失；CI 下界 > 0 → 事實卡損失了區分力 |
| G3 | RAW 評分者自述知道後來有問題（問題組） | 預期 ≤ 2/27（結果在截止之後）。知道者在敏感度分析中排除整對 |
| G4 | RAW 評分者認出公司的比例 | 描述性（未遮蔽，預期大多認出） |
| G5 | RAW 扣除 MEM（只給名稱）線性部分後的殘差 AUC | 描述性；衡量完整年報超出「公司類型先驗」的部分，與第九輪 J0 的殘差 0.65 比較 |
| 參考 | RAW 與 J0、MEM 的 Spearman 相關 | 描述性 |

判讀：
- G1 通過、G2 包含 0 → 事實卡在擋住記憶的同時沒有明顯損失資訊
- G2 下界 > 0 → 事實卡有資訊損失；報告損失大小，並作為改進事實卡的依據
- RAW 的分數仍可能含「公司類型先驗」（認得公司但不知道結果），所以 G5 與 MEM 必須一起報告

## 4. 已知限制
- 27 對樣本小，G2 的 CI 預期很寬
- 未遮蔽年報讓模型認得公司，RAW 不能用來證明「不含記憶」，只能在「結果不可能被記得」的前提下作為資訊上限
- 4.02 是重編，不等於舞弊
