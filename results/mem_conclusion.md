# 第八輪 MEM（只給公司名稱）高 AUC 的來源：結論（2026-11-09）

## 一句話結論
第八輪 MEM 只給 LLM「公司名稱＋會計年度」就得到 AUC 0.88。我們證明了兩件事：
1. **這個分數不是上網查到的**：在拿掉所有工具、可由伺服器端紀錄驗證無法上網的環境中，Opus 5.5 重跑 6 次（雲端 5 次＋使用者 Mac 1 次）都得到 0.86–0.89。
2. **這個分數主要來自模型「記得這些公司後來出事」，而不是從名稱推測公司類型**：模型說「知道出事」的問題公司給 75–85 分、說「不知道」的只給 5–10 分；扣掉「知不知道」之後只剩 AUC 0.54；這些「知道」自述 97% 與 SEC 紀錄相符；記得越少的模型 AUC 越低。

因此，第七輪「整份 10-K 直接評分」的 0.90，不能解讀為 LLM 從年報內容辨識舞弊的能力；在第八輪這類模型記得結果的樣本上，它主要反映記憶。

## 1. 要排除的資訊來源
| 來源 | 如何排除 | 證據 |
|---|---|---|
| 上網（搜尋、抓網頁、指令） | 移除所有工具 | 啟動時工具清單為空、輸出無工具呼叫、伺服器端搜尋計數 0 |
| 讀到 repo 裡的標籤或結果 | 沒有檔案工具，在空目錄執行 | 同上 |
| 過去對話、記憶功能、設定檔 | 不讀任何設定、不保存 session；不用 claude.ai App | `--setting-sources ""`、`--no-session-persistence` |
| 輸入格式洩漏組別 | 統一名稱與日期格式，每次打亂順序 | 第八輪原始清單的格式差異已消除，結果不變 |

## 2. 實驗環境（重點）
每次評分都是一個全新的 Claude Code session：
```
claude -p "<提示詞＋名單>" --model <模型> --tools "" --strict-mcp-config --setting-sources "" \
       --no-session-persistence --output-format stream-json --verbose
```
在一個新建的空目錄中執行。

**為什麼這樣就無法上網**：模型本身只產生文字，要上網必須呼叫工具；`--tools ""` 拿掉全部內建工具（WebSearch、WebFetch、Bash、讀寫檔、子代理、Skill、ToolSearch），`--strict-mcp-config` 不載入任何 MCP 伺服器。

**為什麼不用 claude.ai App、不靠 sandbox**：App 的網路開關需手動操作、事後無法證明，且記憶與「搜尋過去對話」可能帶入先前結果；網路搜尋在 Anthropic 伺服器端執行，只擋網路的 sandbox 擋不住。

**每次執行自動檢查 7 項**（`experiment/mem_isolated.py verify`），缺少證據即判失敗：工具清單為空、MCP 清單為空、無工具呼叫、伺服器端搜尋／抓取計數為 0（含每一個模型）、無子代理、單輪、正常完成。

**檢查本身也被驗證過**：
- 無工具時問截止後的台股收盤：模型答「不知道」，7 項全過
- 只開放 WebSearch 時：搜到並答出點數，檢查判定失敗
- 發現：Claude Code 的搜尋由另一個模型（Haiku）在伺服器端執行，計數只出現在該模型名下；只看主模型的計數會漏掉，所以檢查每一個模型
- Sonnet 5.5 在無工具時，曾在回答文字中寫出 `curl` 證交所網站的工具呼叫——想上網但沒有工具可用，什麼都沒執行。這說明只靠「請不要上網」的提示不夠

**流程保證**：每個實驗都先 commit 預先登錄文件，原始紀錄 commit 之後才讀標籤；評估程式會檢查紀錄已 commit 且未修改。

## 3. 資料
| 樣本 | 內容 | 模型能否記得結果 |
|---|---|---|
| 第八輪 | 14 對：AAER（SEC 會計執法）問題公司＋同產業同規模對照，共 28 家 | 能（多數 AAER 在模型訓練截止 2026-06 前已公開） |
| 時間外 | 第九輪 27 對：2026-07～10 申報 8-K Item 4.02（財報不可再依賴）的公司＋對照，共 54 家 | 不能（事件在訓練截止之後） |

輸入只有「公司名稱 — fiscal year ended YYYY-MM-DD」，模型對每家給 0–100 的重大誤述風險分數，並回答是否知道該年度後來有會計問題、重編或 SEC 執法，附一句理由。

## 4. 實驗與結果
### 實驗 A：隔離環境重跑第八輪 MEM（`results/mem_isolated/`）
| 條件 | AUC |
|---|---|
| 隔離 5 次（雲端） | 0.86–0.89；平均分數 **0.88**（95% CI 0.69–1.00） |
| 使用者在自己 Mac 上親自執行 1 次 | 0.86 |
| 原始第八輪、兩次 claude.ai 重跑 | 0.88、0.88、0.88 |

6 次全部通過 7 項無上網檢查；與原始結果 Spearman ρ 0.96–0.98。

### 實驗 B：時間外樣本（`results/mem_isolated_oot/`）
- 同一環境、同一提示，5 次：模型 **0/27** 知道任何問題公司後來出事，AUC 仍有 **0.69**（0.54–0.83）
- 判讀：名稱本身帶有「公司類型先驗」（OTC 小型公司給 40–55 分，IMAX、Liberty Global 這類大公司給 5–10 分）。這個先驗在一般樣本上存在，需要在第八輪樣本上拆開

### 實驗 C：三個模型（`results/mem_models/`）
| 模型 | 第八輪 AUC | 時間外 AUC | Δ（記憶增量） | 第八輪問題公司說「知道」 |
|---|---|---|---|---|
| Opus 5.5 | 0.88 | 0.69 | +0.18 | 90% |
| Sonnet 5.5 | 0.84 | 0.69 | +0.15 | 93% |
| Haiku 5.5 | 0.79 | 0.70 | +0.09 | 67% |

- 時間外樣本上三個模型幾乎相同 → 不知道結果時，只剩共同的公司類型先驗
- 記得最少的 Haiku，第八輪 AUC 與 Δ 都最低。Sonnet 的「知道」比例與 Opus 相近但 AUC 較低，原因見實驗 D（它對對照公司也常說「知道」）

**「知道／不知道」分層（第八輪樣本）**
| 模型 | 只用「知道」旗標的 AUC | 扣掉「知道」後的殘差 AUC | 問題公司：知道／不知道 中位數分數 |
|---|---|---|---|
| Opus 5.5 | 0.89 | **0.54** | 85 ／ 5 |
| Sonnet 5.5 | 0.81 | 0.63 | 80 ／ 5 |
| Haiku 5.5 | 0.76 | **0.54** | 75 ／ 10 |

- 只用「知道」排序就幾乎等於整體 AUC；扣掉之後接近隨機
- 第八輪樣本的殘差（0.54–0.63）低於時間外樣本的先驗（0.69）：在這批 AAER 公司上，名稱帶來的類型先驗很弱

### 實驗 D：「知道」自述是真實記憶嗎（`results/mem_factcheck/`）
- 254 則「知道」自述，逐則與 SEC 紀錄比對（14 份 AAER 原文；EDGAR 8-K 4.02、10-K/A、延遲申報紀錄）
- 評分者：每家公司一個無工具 Opus session，看不到自述來自哪個模型；人工抽查 51 則，總判定一致 **94%**

| 模型 | 第八輪問題公司「知道」與紀錄相符 | 其中說得出具體問題類型 | 對照公司／時間外的「知道」沒有紀錄支持 |
|---|---|---|---|
| Opus 5.5 | **97%** | 86% | 第八輪對照 5/9（全是 Welbilt）；時間外 0 則 |
| Sonnet 5.5 | **86%** | 69% | 第八輪對照 17/22；時間外 32/33 |
| Haiku 5.5 | **83%** | 40% | 第八輪對照 5/10；時間外 3/5 |

- 三個模型都超過預先登錄的 80% 門檻 → 「知道」是真實記憶，實驗 C 的分層可以解讀為記憶
- 錯誤多是細節記錯：GTT 把「營業成本」記成「營收」；Evoqua 說 FY2018 被重編（實際只有 SEC 處分、沒有重編）
- Sonnet 會對沒有紀錄的公司說「知道出事」，解釋了它 AUC 較低
- MEM 每次都輸的兩對也由記憶解釋：**Gentex** 模型不記得出事（4–5 分）；**Welbilt**（對照）三個模型都記得它真實的所得稅重編，但那是 2016 年的事，被套到被問的 2018 年，給了 80–85 分

## 5. 證明的邏輯
1. 實驗 A：環境上不可能上網，而分數不變 → 0.88 不是上網得到的
2. 實驗 B：模型不知道結果時，名稱先驗約 0.69 → 需要拆開先驗與記憶
3. 實驗 C：在第八輪樣本內，分數幾乎完全跟著「說知道」走，扣掉後 0.54；記得越少的模型 AUC 越低
4. 實驗 D：「說知道」97%（Opus）與 SEC 紀錄相符，不是看名字亂猜
→ 第八輪 MEM 的 0.88 主要來自模型記得這些公司後來出事

## 6. 對整體研究的意義
- 第七輪「整份 10-K 直接評分」0.90 與 MEM 0.88 幾乎相同；在第八輪這類模型記得結果的樣本上，這個分數主要是記憶，不能當作 LLM 讀年報辨識舞弊的能力
- 先前第九輪 g（`origin/claude/dreamy-volta-i6oimk` 的 `results/round9g/`）在時間外樣本上，整份 10-K 得到 0.76；本次時間外 MEM 為 0.69。兩者的差距才比較接近「讀年報」的貢獻
- 任何 LLM 評分方法都應在時間外樣本、或確認模型不知道結果的條件下評估

## 7. 限制
- 第八輪只有 14 對，AUC 的 CI 很寬（約 0.6–1.0）；三個模型只能看方向，不做顯著性檢定
- 第八輪（AAER 公司）與時間外（小型 4.02 公司）樣本組成不同，兩者 AUC 的差距不能全歸給記憶；這是用實驗 C 的同樣本分層來補
- 「知道」是模型自述；實驗 D 的「紀錄」只含 EDGAR 8-K 4.02 與 AAER 清單，SEC 的其他程序不在內，「SEC 執法」類自述可能判得偏嚴
- 評分者與被評的是同一系列模型；以人工抽查 94% 一致作為檢查
- 只用 Claude 家族的三個模型；effort 用 CLI 預設值
- 看不到模型完整的思考內容（目前模型不回傳原始思考）；但上網只能透過工具，工具紀錄與伺服器計數才是證據
