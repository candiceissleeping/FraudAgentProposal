# 第八輪結果：去除記憶污染的 LLM 舞弊風險評分

> 設計與通過標準見 [`protocol.md`](protocol.md)（在執行任何 agent 前提交）；程式產生的完整數字見 [`evaluation.md`](evaluation.md)。
> 樣本：第七輪的 28 份 10-K（14 家 2023 年後 AAER 問題公司 + 14 家同產業同規模對照）。評分者：每次都新開的 Claude agent。共約 230 個 agent。

## 一句話結論
- **目標一（讓評分的 LLM 不知道是哪家公司、不知道後來被 AAER）：對評分者本身達成，但無法對「有心的攻擊」保證。** 評分 agent 28 份全部說不出公司、也都不知道後來有問題；但只要給一份候選名單，模型就能把事實卡對回公司（26/28，粗化後仍 18/28）。
- **目標二（分數來自推理而非記憶）：有強烈證據支持，但還不能證明記憶的影響為零。** 改動事實，分數 14/14 往正確方向大幅移動；加上公司名稱，分數就往「記憶中的答案」移動，拿掉名稱這個效應就消失。
- 依預先登錄的判讀規則，**J0 的 AUC 0.67 不能當作「保證乾淨」的估計**。要真正證明，需要模型訓練截止後才發生的案例（第九輪提案）。

## 1. 主要數字

| 條件 | 評分者看到什麼 | AUC | 95% CI | 組內勝/平/負 |
|---|---|---|---|---|
| 第七輪 B | 整份 10-K，不遮蔽 | 0.90 | 0.73–1.00 | 13/0/1 |
| MEM | **只有公司名稱與年度**（沒有任何年報） | **0.88** | 0.72–1.00 | 11/1/2 |
| J1 | 事實卡 + 真實名稱 | 0.84 | 0.65–1.00 | 12/0/2 |
| **J0（本輪方法）** | **事實卡，無名稱** | **0.67** | 0.46–0.86 | 10/0/4 |
| J0-C（8b） | 粗化事實卡，無名稱 | 0.69 | 0.49–0.87 | 9/0/5 |
| J2 | 事實卡 + **對調**的名稱 | 0.40 | 0.20–0.62 | 5/0/9 |
| 參考：F-score（第七輪） | 程式計算 | 0.67 | 0.44–0.89 | 7/0/6 |

讀法：
- **只給名字、不給年報，模型就有 0.88**。這就是「記憶」能貢獻的量，幾乎等於第七輪整份年報的 0.90。第七輪的高分確實是記憶。
- 拿掉名稱後（J0）掉到 0.67；把名稱加回去（J1）又升到 0.84；把名稱對調（J2）掉到 0.40——**名稱就是記憶的開關**。

## 2. 目標一：辨識是否被切斷

| 檢驗 | 結果 | 標準 | 判定 |
|---|---|---|---|
| G1c 評分 agent 自述「知道後來有問題」 | **0/28**（第七輪不遮蔽：13/14 問題公司） | ≤ 1/28 | 通過 |
| G1c 評分 agent 猜中公司名稱 | **0/28**（第七輪 28/28；第四輪遮蔽文字 62/72） | – | – |
| G1a 開放式辨識（盡力猜公司） | **1/28**（CPI Aerostructures，信心 15%） | ≤ 2/28 | 通過 |
| G1b 封閉式辨識（給 28 家名單） | **26/28** | 不顯著高於產業隨機猜（期望 5） | **未通過** |
| 8b 粗化卡封閉式辨識 | **18/28**（指派到同組 20/28） | ≤ 3/28 | **未通過** |

- 封閉式探針的理由顯示它靠的是：產業大類、精確比率、少見事實（SPAC／反向合併、單一客戶 96%、銀行），再對照它對每家公司的記憶。例如「稅務重大缺失 + 重編 + 集體訴訟 + 換 CEO」→ Welbilt。
- 粗化（拿掉產業、比率改類別）只把 26 降到 18。**剩下的辨識力來自「年報事實本身」**——內控缺失、重編、訴訟這些正是判斷舞弊最需要的資訊，也正是模型記得的公司特徵。這是本輪最重要的發現：**對知名度足夠的公司，有用的資訊與可辨識的資訊無法完全分開。**
- 但要注意：封閉式探針拿到「答案就在這 28 家裡」的提示，評分 agent 沒有。實際評分時，評分者在開放情境下 0/28 認出、0/28 知道結果。

## 3. 目標二：分數是否來自推理

| 檢驗 | 結果 | 標準 | 判定 |
|---|---|---|---|
| G2a 理由引用有效欄位 | 242/242（100%） | ≥ 95% | 通過 |
| G2b 內容擾動 | **14/14 方向正確，\|Δ\| 中位數 34 分** | ≥ 12/14 且中位數 ≥ 10 | 通過 |
| G2c J0 與純記憶分數的組內相關 | ρ = 0.45（第七輪 B：0.74） | 描述性 | – |
| 名稱效應 J1 − J0 | 問題公司 +8.4，對照 −8.1（記憶效應指數 +16.6） | 描述性 | – |
| 對調名稱 J2 − J0 | 問題公司卡（標對照名）−10.2；對照卡（標問題名）+8.2 | 描述性 | – |

證據一：**分數跟著內容走**
- 把問題公司卡上的紅旗改成「無」，分數平均下降（例：Ideanomics 72 → 35）；在乾淨的對照公司卡加上三個紅旗，分數平均上升（例：Visteon 14 → 62）。14 張全部方向正確。

證據二：**記憶確實存在，而且由名稱觸發**
- 同一張卡，只是多了名稱，分數就往記憶中的答案偏約 8 分；名稱對調，偏移方向也跟著對調。J1/J2 的評分 agent 在理由中也直接寫出「我記得這家公司後來重編」。
- J0 沒有名稱，這個開關被拿掉。

證據三：**J0 對「年報裡看不出來」的問題公司給低分**（記憶給高分）

| 公司 | 純記憶 MEM | J0 | 說明 |
|---|---|---|---|
| SAExploration | 95 | 38 | 隱藏的關係人交易，年報看不到 |
| USA Technologies | 90 | 35 | 營收認列問題當年未揭露 |
| GTT | 88 | 30 | 成本認列問題事後才爆 |
| Plug Power | 80 | 28 | 租賃會計問題事後才重編 |
| ADM | 55 | 28 | 部門間交易問題事後才揭露 |

- 若 J0 在偷用記憶，這幾家應該拿高分。它們拿低分，代表 J0 的分數主要來自卡片上的內容。
- 反過來，對照公司中年報本身就有紅旗的（Welbilt：稅務重大缺失與重編；theMaven：會計師異議與內控缺失），J0 給高分（70、62），這是「讀出來」的，不是記憶。

尚未排除的部分：
- G2c ρ = 0.45 不是 0。一部分可能是正常的（記憶中「有問題的公司」通常年報本身也較多紅旗），但也可能是殘留的隱性記憶。本輪的設計無法把兩者分開。

## 4. 依預先登錄規則的判定
- G1：G1a、G1c 通過，**G1b 未通過**（8b 粗化後仍未通過）→ 事實卡仍帶有可辨識的指紋，J0 的 AUC 0.67 **不能宣稱為保證乾淨**
- G2：G2a、G2b 通過 → 評分對內容敏感，理由可追溯

## 5. 給提案的結論
1. **「只遮蔽」不夠，「瓶頸」有用但不足以證明。** 抽事實 → 事實卡 → 判斷的流程，讓評分者在實際情境下認不出公司（28/28 → 0/28），分數也確實由內容驅動。但只要模型記得某家公司的特徵，事實卡本身就是指紋。
2. **唯一能「證明」的辦法是時間外測試**：用模型訓練資料截止之後才曝光的案例，模型不可能記得結果，辨識與否都無妨。
3. 本輪的乾淨估計（有條件）：事實卡方法 AUC ≈ 0.67–0.69，與 F-score（0.67）相當；不遮蔽版的 0.90 中約有 0.2 來自記憶。

## 6. 限制
- 14 對，AUC 信賴區間很寬
- 評分者、抽取者、探針都是同一個 Claude 模型；抽取 agent 讀的是遮蔽後的全文，可能認得公司而「選擇性」找證據（欄位固定、引文驗證可降低但不能排除）
- 擾動測試只改了紅旗欄位，比率不變；且是「加入／拿掉一整組紅旗」，屬於強擾動
- 評分 agent 在雲端 session 中技術上可讀到 repo 其他檔案；提示詞禁止，且回報都寫「只讀了兩個檔案」，但沒有程式強制
