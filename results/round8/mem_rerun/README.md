# 第八輪 MEM 重新執行（2026-11-03）

## 為什麼重跑
原始輸入清單（`data/round8/cards/memory_only.txt`）有格式洩漏：問題公司用簡稱與 `YYYY-MM-DD` 日期，對照公司用全大寫正式名稱與 `YYYYMMDD` 日期，依字母排序。模型理論上可從格式分出兩組。

## 這次的做法
- 輸入：28 家公司統一用正式名稱、統一 `YYYY-MM-DD`，以種子 20261103 打亂順序（`input.txt`）
- 提示：與原始 `data/round8/memory_prompt.md` 相同內容，改為在對話中直接回覆 JSON，並要求不得搜尋網路
- 執行：使用者在一般 Claude Opus 5.5 對話中執行（新對話），輸出存於 `output.json`

## 結果
| | 原始（第八輪） | 重跑 |
|---|---|---|
| AUC | 0.88 | **0.88**（95% CI 0.72–1.00） |
| 組內勝 / 平 / 負 | 11 / 1 / 2 | 12 / 0 / 2 |
| 問題公司「知道後來出事」 | 13/14 | 12/14（Evoqua、Gentex 不知道） |
| 對照公司「知道後來出事」 | 2/14（Welbilt、TheMaven） | 2/14（同） |

輸的兩對：Evoqua 25 < Welbilt 60（對照公司本身重編過）；Gentex 5 < Visteon 8（模型不知道 Gentex 出事）。

結論：格式統一、順序打亂後結果相同。原始 0.88 不是格式洩漏造成的，而是模型記得哪些公司出過事。
