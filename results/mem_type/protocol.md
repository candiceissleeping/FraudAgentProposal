# 實驗 E：除了「記不記得出事」，模型有沒有用到公司類型？（預先登錄，2026-11-09）

本文件在建立任何類型卡、下載任何本實驗資料、執行任何本實驗 session 之前提交。只用 Claude Opus 5.5。

## 0. 目的
第八輪 MEM（只給名稱＋年度）AUC 0.88。模型可能用了兩種資訊：
- 記得這家公司後來出事（記憶）
- 公司類型：產業、規模、上市地點、成立多久等，不需要知道結果

本實驗只回答：**在第八輪同一批 28 家公司上，光靠公司類型能分出問題公司與對照公司到什麼程度？**

## 1. 兩個部分
### E1：分層分析（沿用已 commit 的資料，不新執行）
Opus 5.5 在 `results/mem_isolated` 的 5 次執行（實驗 A）。依 `results/mem_models/protocol.md` §6 的定義：
只用「知道」旗標的 AUC、扣掉「知道」後的殘差 AUC、四格中位數。已算出：0.89、0.54（`results/mem_models/evaluation.md`）。本實驗只把它從實驗 C 移到這裡，不重新定義。

### E2：只給公司類型卡、不給名稱（新執行）
**類型卡內容**（全部是該會計年度當時的資訊，不用任何之後的資料）：
| 欄位 | 來源 | 分級 |
|---|---|---|
| 產業 | 抽樣時記錄的 4 位數 SIC 與其名稱 | 原樣 |
| 會計年度結束日 | 樣本定義 | 原樣 |
| 總資產 | 該年度 10-K 的 XBRL `Assets`（期末） | 未滿 1 千萬／1 千萬–1 億／1–10 億／10–100 億／100 億以上（美元） |
| 公開流通市值 | 該年度 10-K 的 XBRL `dei:EntityPublicFloat` | 未滿 1 千萬／1 千萬–7,500 萬／7,500 萬–2.5 億／2.5–7 億／7–50 億／50 億以上 |
| 掛牌交易所 | 該年度 10-K 封面「Section 12(b)」登記的交易所 | Nasdaq／NYSE／NYSE American／無（未在交易所登記） |
| 在 SEC 申報的年數 | EDGAR 第一筆申報日到會計年度結束日 | 未滿 3 年／3–10 年／10–20 年／20 年以上 |

不給：名稱、股票代號、地址、任何會計年度之後的資訊（例如 EDGAR 目前的交易所狀態，因為下市本身就是事後結果）。缺值寫「未提供」。

**確認卡片認不出公司（封閉式配對）**
- 每份樣本一個無工具 Opus session：給全部名稱（含年度）與全部類型卡，要求一一配對
- 通過標準：第八輪 ≤ 3/28 配對正確；時間外 ≤ 3/54
- 不通過就依序粗化，取通過的最細等級：
  - L2：產業改為 SIC 前 2 碼的大類名稱；資產、流通市值各合併為 3 級（未滿 1 億／1–10 億／10 億以上；未滿 7,500 萬／7,500 萬–7 億／7 億以上）；結束日只留年份
  - L3：再拿掉產業
- 兩份樣本用同一個等級（取兩者都通過的最細等級）；L3 仍不通過，照樣以 L3 評分並在報告中標示

**評分**
- 提示與 MEM 相同的結構，只把「公司名稱＋年度」換成類型卡；另外要求每張卡回答：猜是哪家公司（或 unknown）、是否知道後來出事
- 第八輪 28 張、時間外 54 張，各 5 次，每次以不同種子打亂順序
- 環境與檢查同實驗 A（無工具、7 項檢查、先跑 canary）；原始紀錄 commit 後才讀標籤

## 2. 指標
- E2 第八輪 AUC（5 次各自、5 次平均分數，bootstrap 95% CI）
- E2 時間外 AUC（驗證類型卡是否抓到名稱帶的類型資訊；比較對象：只給名稱的 0.69）
- 評分時猜中公司的比例、說「知道出事」的比例（預期都接近 0）
- 與 E1 殘差（0.54）、只給名稱的 MEM（0.88）比較

## 3. 判讀（事先寫下）
| E2 結果 | 判讀 |
|---|---|
| 時間外類型卡 AUC 接近 0.69（≥ 0.62），且第八輪類型卡 AUC ≤ 0.62 | 類型卡抓得到類型資訊，但在第八輪這批公司上類型分不出來 → 0.88 幾乎全靠記憶，與 E1 一致 |
| 第八輪類型卡 AUC ≥ 0.69 | 公司類型在第八輪也有明顯貢獻 → 修正結論：0.88 是記憶加類型 |
| 時間外類型卡 AUC < 0.62 | 類型卡沒有抓到名稱帶的類型資訊（名稱還帶有知名度、形象等），E2 只能說明「這些可量化的類型欄位」的貢獻，保守解讀 |
| 評分時猜中公司或說「知道」超過 2/28 | 卡片仍洩漏身分，標示並做排除後的敏感度分析 |

## 4. 限制（事先寫下）
- 類型卡只涵蓋可量化的欄位；名稱可能還帶有知名度、新聞形象等資訊
- 對照公司是依產業與規模配對選出的，同一對的產業與資產本來就接近，類型卡的差異主要來自流通市值、交易所與申報年數
- 第八輪只有 14 對，CI 很寬

## 6. 修訂 2：E2 第二版（事後追加，2026-11-09）
**這一節在看過 E1 與 E2（L3）結果之後寫成，在執行任何 L1／L2 評分 session 之前提交。L1、L2 的評分結果寫這一節時沒有人看過。**

### 為什麼改
原本以「給名單配對 ≤ 3 家」當門檻，三個等級都沒通過（L1 26/28、L2 24/28、L3 20/28），只好用沒有產業的 L3。
這個門檻測的是「手上有名單時能不能對上」，不是 E2 真正擔心的事。E2 擔心的是：**評分當下，模型沒有名單，卻自己認出公司而用上記憶。** 這可以在評分回答中直接量。
因此改用「評分時的開放式辨識」當門檻，從資訊最多的 L1 開始。

### 新門檻（開放式辨識）
在每份樣本的 5 次評分回答中，計算：
- **猜中**：`company_guess` 指向正確公司（程式比對名稱主要字詞後，由協調者逐一人工確認所有非 "unknown" 的猜測，並記錄判定）
- **說知道**：`knows_later_problems = true`
- 通過：每次平均猜中 ≤ 2 家且說知道 ≤ 2 家（第八輪 28 家）；時間外 54 家為每次平均 ≤ 4 家
- 兩份樣本都通過才算該等級通過

### 流程
1. 先跑 L1（含 4 位數產業名稱、精確結束日、5 級資產、6 級流通市值），兩份樣本各 5 次；提示、環境、種子、檢查與 L3 完全相同
2. 原始紀錄 commit 後，先只算開放式辨識（不讀標籤）
3. L1 通過 → L1 為 E2 第二版的主要結果；不通過 → 依序跑 L2，再不通過 → 以已完成的 L3（猜中 0、說知道 0，已通過此門檻）為結果
4. 通過的等級才讀標籤算 AUC；判讀標準沿用 §3
5. 敏感度分析：任何在 5 次中被猜中 ≥ 2 次的公司，連同其配對公司排除後再算一次 AUC

### 報告方式
- 第一版（L3、原門檻）照原樣保留，不覆蓋
- 第二版標為「事後追加」，兩版並列報告
