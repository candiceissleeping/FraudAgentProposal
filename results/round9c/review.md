# 第九輪 c 結果：給名單也認不出公司的評分輸入

> 設計見 [`protocol.md`](protocol.md)（在建立任何 9c 卡片、執行任何 9c agent 前提交）；程式輸出見 [`evaluation.md`](evaluation.md)。
> 樣本：第九輪的 54 份 10-K（27 家截止後 4.02 公司 + 27 家對照），同一份已驗證事實與 XBRL 特徵。

## 一句話結論
- **類別計數卡（L2）在對抗情境下認不出公司**：給 54 家名單，只配對對 3/54（隨機期望 1.0，p = 0.08，通過預先登錄的 ≤ 3 標準）。
- **而且區分力沒有掉**：L2 卡的 LLM 評分 AUC **0.77（0.63–0.88）**，與完整事實卡（0.77）相同。評分者 0/54 猜名稱、0/54 知道後來出事。
- 扣除「只看名稱」的先驗後，L2 的殘差 AUC 是 0.69（0.53–0.82），CI 下界高於 0.5，比完整卡的殘差（0.65，0.50–0.80）更明確。

## 1. 匿名化階梯

| 等級 | 卡片內容 | 給名單配對正確 | 判定 | LLM 評分 AUC |
|---|---|---|---|---|
| J0（第九輪） | 產業 + 28 欄位 + 精確比率 | 34/54 | ✗ | 0.77 |
| L1 | 28 欄位 + 比率類別（無產業） | 16/54 | ✗ | 未評（未通過） |
| **L2** | **7 個面向的紅旗計數（不說是哪一項）** | **3/54** | **✓** | **0.77（0.63–0.88）** |
| L3 | 只有紅旗總數 + 數字訊號數 | 1/54 | ✓ | 未評（L2 已通過）；程式計數 0.74 |

讀法：
- 讓模型認得出公司的是**個別事實的組合**（哪一種內控缺失、哪一種訴訟、哪個比率特別高）。只要不說是哪一項、只說「這個面向有幾個紅旗」，指紋就消失了。
- 但判斷舞弊風險需要的資訊，大部分在「有幾個紅旗、分布在哪些面向」，所以區分力保留下來。

L2 配對正確的 3 家（信心都只有 10–12）：CreditRiskMonitor（紅旗幾乎為 0）以及兩家銀行 Skyline Bankshares、BayFirst Financial。銀行的「數字訊號可計算項數 = 2」間接透露了產業；名單裡剛好只有兩家銀行，被分別配對正確。之後可把「可計算項數」也拿掉或統一。

## 2. 和其他基準比較

| 條件 | AUC | 95% CI |
|---|---|---|
| **J0-K：L2 卡 + LLM 評分** | **0.77** | 0.63–0.88 |
| J0：完整事實卡 + LLM 評分 | 0.77 | 0.64–0.89 |
| 程式：紅旗總數 + 數字訊號數（不用 LLM） | 0.74 | 0.60–0.87 |
| 程式：揭露紅旗總數 | 0.72 | 0.58–0.85 |
| MEM：只給名稱（模型不知道結果） | 0.71 | 0.56–0.83 |
| J0-K 扣除 MEM 線性部分 | 0.69 | 0.53–0.82 |

- LLM 在 L2 上的加值：比單純加總紅旗多 0.03–0.05，差距在信賴區間內。**誠實的說法是：在這個樣本上，LLM 判斷的價值主要來自「抽事實」這一步，而不是最後的加權判斷。**
- J0-K 與名稱先驗 MEM 的相關仍有 ρ = 0.70，但 J0-K 的輸入**完全認不出公司**（3/54 ≈ 隨機），所以這個相關不可能來自「認出公司 → 想起來」，只能來自兩者都反映了同一個真實特徵：公司處於高風險狀態。

## 3. 兩個目標的最終判定（第九輪 + 9b + 9c）

**目標一：讓 LLM 不知道是哪家公司、不知道後來有 AAER**

| 層次 | 證據 | 判定 |
|---|---|---|
| 不知道後來有 AAER／出事 | AAER 0/3（9b，截止後發布）；4.02 0/27（K1）；看不到名稱的評分者 0/114 自述知道（J0 54 + L2 54 + 9b J0 6）。看得到名稱的 J1：1/60（Latch，知道的是截止前已公開的 2022 年重編，不是 AAER） | **達成**（時間設計保證 + 逐家確認） |
| 評分者在實際情境下認不出公司 | 開放式辨識 0/60；評分者猜名稱 0/114 | **達成** |
| **即使給候選名單也認不出公司** | **L2 卡 3/54（隨機 1.0，p = 0.08）** | **達成**（9c） |

**目標二：分數來自推理（年報內容）還是記憶 → 來自推理**

| 證據 | 結果 |
|---|---|
| 輸入認不出公司、結果不可能被記得，仍有區分力 | **L2：AUC 0.77（0.63–0.88）**；完整卡 0.77；AAER 3/3 組內正確 |
| 加名稱不再提升 | 記憶效應 +3.6（CI 含 0）；第八輪時間內 +16.6 |
| 改動內容，分數跟著動 | 12/12（中位數 34 分） |
| 年報看不出的問題拿低分 | AAER 的 T+L、Bancorp 只有 22–24 分 |

## 4. 限制
- 27 對 4.02 + 3 對 AAER；4.02 不等於舞弊
- L2 通過標準剛好落在門檻（3/54）；兩家銀行靠「可計算項數」被配對
- 抽取、評分、探針都是同一個模型
- L2 卡的評分者無法按提示詞引用 F/R 欄位編號（卡上沒有），改為引用面向名稱；所有評分者都在理由中註明
