# 盲測評分規則（預先登錄 / Pre-registered rubric）

本檔在**閱讀任何盲測資料包之前**提交到 git，提交時間即為登錄時間；評分不得偏離本規則。

## 輸入
每家公司一份資料包 `results/blind_packets/Bxx.md`：
- 公司名稱、產品名、主要人物姓名已替換為 `[COMPANY]` / `[REDACTED]`
- 內容固定為：Item 9A、Item 9、Item 3 開頭，以及一組**固定查詢**（每項最多 2 段原文）
- 每家用同一組查詢，不針對個別公司加查

## 計分（0–100，各面向有上限，每一分都必須附原文引句）

| 面向 | 項目 | 分數 |
|---|---|---|
| A. 財報可信度（上限 40） | 實質重編已發布數字（不含拆股、合併追溯、新準則等機械性調整） | 15 |
| | 當期或前一年度內控重大缺失 | 15 |
| | 會計師辭任 / 解任且有意見不合或可報告事件 | 10 |
| | 持續經營疑慮 | 15 |
| B. 關係人與治理（上限 25） | 對董事 / 主管 / 其家族的借款、擔保或共同借款 | 15 |
| | 與內部人控制實體的重大交易 | 10 |
| | 目的不明的未合併實體 / VIE 且公司提供擔保或資金 | 10 |
| C. 盈餘品質（上限 20） | 營收或損益高度依賴判斷性估計（Level 3、mark-to-model、通路庫存、交換 / IRU、備抵） | 10 |
| | 有利於盈餘的會計政策或估計變更 | 5 |
| | 成長主要來自漲價或併購，且強調非 GAAP 指標 | 5 |
| D. 法律 / 監管（上限 15） | 針對公司行為的政府調查 / 傳票 | 10 |
| | 證券詐欺集體訴訟 | 5 |
| | 僅有產品 / 反壟斷 / 勞資訴訟 | 3 |
| E. 財務壓力（上限 10） | 違反契約條款 / 豁免、信評調降、流動性警告 | 10 |

等級：0–24 Low、25–49 Moderate、50–74 Elevated、75–100 High。

## 程序
1. 依資料包編號順序評分，寫入 `results/blind_scores.md` 並提交 git。
2. 提交後才執行揭盲（`python -m experiment.edgar_risk.blind --unblind`）。
3. 揭盲後不得修改分數；任何事後評論另外標示。

## 已知限制
- 評分者（Claude）自己挑選樣本，知道樣本包含哪些公司，只是不知道編號對應 → 不是完全盲測。
- 年份、產業描述仍可能透露身分；若評分時認出公司，必須在該家評分中註明「疑似認出：○○」。
