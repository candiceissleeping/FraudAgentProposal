## 3. 解讀

1. **「小公司」不等於「模型不知道」**。本輪 10 家都是 2020–2022 年的 AAER 或 SEC 案件，其中 9 家模型都記得後來的重編或執法，而且描述大致正確（Pareteum 營收重編、PSI bill-and-hold、Lottery.com 3,000 萬未收款、HF Foods 的 Hindenburg 報告、Tandy 存貨重編等）。這些案子都有放空報告、WSJ 調查、下市或刑事起訴等新聞。第九輪的 Netcapital、C-Bond 之所以不知道，關鍵是**執法時間**（晚於訓練截止日）或**新聞量極低**，而不是公司規模
2. **主要分析仍只有 3 對，而且只有 1 對是清楚的「讀出」**：
   - Netcapital：+66 / +50，理由對準實際手法（第九輪已說明）
   - C-Bond：+5 / 0，沒有讀出
   - **Apex（新增）**：+1 / +5，分數幾乎等於對照公司。但兩個 agent 的理由都**直接點到實際的錯報**：「Target 退出後主品牌權利金下滑 52%，主品牌商標卻沒有減損」「減損部分是為了『對齊市值』」。SEC 的 AAER-4199 正是指控未及時認列商標減損。模型讀到了正確的訊號，卻沒有把它當成高風險；同時它也把類似的減損判斷問題用在對照公司 Differential Brands（27 / 25）
3. **「知道」與「不知道」的分數差約 23–28 分**（L0′ 67 vs 44；L3c 66.5 vs 39），方向與第八輪 Latch（以為是 Latch 約 68 vs 以為是 SmartRent 約 27）一致。但這是觀察性比較：模型記得的案子往往也是規模大、手法明顯的舞弊，兩者無法分開
4. **在知道後來出事的 10 家中，高分理由多半有年報內證據**：PSI 未出貨 bill-and-hold 營收從 320 萬跳到 2,140 萬、Pareteum 應收帳款一年增加約 7.5 倍、Lottery.com 從 2.6 萬增加到 2,170 萬、HF Foods 對 CEO 關係企業的大量借款。這些都是會計教科書式的警訊；但因模型同時知道結果，仍無法證明它在不知道的情況下會給同樣高分
5. **L0′ 與 L3c 差異很小**（問題公司平均 61.6 → 60.2），個別公司變動 0–23 分（最大為 Tandy +23、RTI −17、Manitex +12），部分超過第八輪估計的重複評分雜訊（約 3–8 分），可能來自遮蔽後內容不同，也可能只是單次評分的變異

## 4. 本輪 L3c 遮蔽殘留（評分後發現，記錄不修改分數）
- **Axcelis（R06C）**：公司名稱「Axcelis」在 L3c 出現 14 次（只遮了全名形式），agent 直接以此認出。對照公司，對主要分析無影響
- **公司名的一部分被保留**：「[COMPANY] Holding Co., Inc.」（Coffee Holding）、「[COMPANY] Leather」（Tandy Leather Factory）——名稱遮蔽只替換了第一個字
- **RTI（R10T）**：9 個「December2013」型月份黏年份的日期未轉換（第九輪的補空格修正沒有作用在這份 2016 年的 HTML 格式上），讓 agent 確定 Y0 = 2015
- 這些都只影響辨識，而本輪 L3c 即使沒有這些殘留，其他 agent 也都靠業務描述（產品、併購、訴訟、合約對象）認出公司。名稱遮蔽不是決定性的

## 5. 結論與下一步
1. 用 AAER 找小公司，模型仍有 9/10 記得後來出事；要切斷「先知道」，**時間**比規模有效：只有晚於訓練截止日的執法（Netcapital）或幾乎沒有新聞的案子（C-Bond、Apex）才行
2. 13 對中只有 3 對可用於主要分析，結果是：1 對明確讀出（Netcapital）、1 對讀到訊號但沒給高分（Apex）、1 對沒讀出（C-Bond）
3. 建議下一步：
   - **以模型訓練截止日之後的 SEC 行動為抽樣框**（2026-06 以後的 AAER / 訴訟），這是唯一能系統性保證「不知道」的方法；先用辨識測試確認
   - 或改用**操弄式設計**（第八輪交換測試結論第 2 點）：在提示詞中告訴模型「後來曾重編 / 從未出事」，直接量測「知道」對分數的效果
