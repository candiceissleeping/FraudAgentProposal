# 第九輪 f：擴大 AAER 樣本（預先登錄）

本文件在篩選任何新案例、建立任何卡片、執行任何 agent 之前提交。

## 0. 目的
第九輪 d／e：在 AAER 樣本（16 對）上，L3 卡的無記憶 AUC 0.62 不顯著。本輪把 AAER 樣本擴大，檢驗「完全認不出公司、不含記憶的 LLM 分數」能否顯著區分 AAER 公司。

## 1. 樣本
- 來源：SEC AAER 清單（`www.sec.gov/enforcement-litigation/accounting-auditing-enforcement-releases`），**發布日 2017-01-01 至 2022-12-31**，被告名稱含公司字樣（Inc、Corp、Company、Ltd、LLC、plc、Holdings 等），排除已在第七／八／九輪樣本的公司、會計師事務所（LLP）、程序性命令
- 逐筆由一個 agent 讀 AAER 命令或起訴書前三頁（`pdftotext`），輸出 JSON：是否 10-K 申報人、是否財報本身錯報（違反 GAAP）、是否只是 FCPA／揭露／內控、錯報的會計年度
- 納入：10-K 申報人 + 財報錯報；排除：FCPA／賄賂、只有揭露或非 GAAP、只有內控、外國發行人
- Y0：錯報年度中**第一個**有原始 10-K（含 XBRL）的會計年度；Y-1：前一份原始 10-K
- 若合格者超過 30 家，以種子 20261104 隨機抽 30 家
- 對照：`round9.controls` 同一演算法（同 SIC、規模 3 倍內優先、期末 ±92 天），排除所有已用公司

## 2. 流程（與第九輪 b 相同）
遮蔽 → 抽取 agent（同一提示）→ 引文驗證 → **L3 紅旗總數卡**（同 9c 格式）→ 新 agent 評分（同判斷提示）

## 3. 檢驗
| 代號 | 檢驗 | 標準 |
|---|---|---|
| F1 | 合併 AAER 樣本（第九輪 d 的 16 對 + 本輪新對）上 J0-L3 的 AUC | **95% CI 下界 > 0.5** |
| F2 | 本輪新卡的封閉式辨識（新名單 + 新 L3 卡，兩次） | 兩次都 ≤ max(3, 期望 × 3) |
| F3 | J0-L3 自述知道後來有問題 | ≤ 1 |
| 參考 | 只看本輪新對的 AUC；程式數紅旗的 AUC | 描述性 |
