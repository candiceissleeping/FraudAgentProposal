# 第九輪 f 結果與最終判定：擴大 AAER 樣本（43 對）

> 設計見 [`protocol.md`](protocol.md)（在篩選任何案例前提交，修訂皆記錄在 §4）；程式輸出見 [`evaluation.md`](evaluation.md)。

## 一句話結論
把 AAER 樣本從 16 對擴大到 **43 對**（新增 27 對 2017–2022 年 AAER 公司）後：
- 只給「紅旗總數」的 L3 卡，評分者 **0/86 猜名稱、0/86 知道後來出事**；給 54 家候選名單也只配對到 **1/54、1/54**（隨機期望 1）
- 同一份分數在合併 AAER 樣本上 **AUC 0.71（95% CI 0.60–0.81）**，下界 > 0.5，**顯著**
- **卡片內容完全相同的公司，AAER 與對照的分數幾乎一樣**：分數殘差 AUC 0.51。分數裡沒有可偵測的記憶成分

| 步驟 | 數量 |
|---|---|
| 2017–2022 AAER 中，被告為公司者 | 133 |
| 程式預篩（FCPA／賄賂、無錯報關鍵字、下載不到）排除 | 51 |

- 54 份 10-K 遮蔽 → 54 個抽取 agent → 614 條引文，**0 條驗證失敗** → L3 卡（只有兩個數字：揭露紅旗 x/24、數字警訊 y/4）

## 3. 分數到底來自推理還是記憶（事後分析）
L3 卡只有兩個整數。若分數是「讀卡片推出來的」，**兩張內容一模一樣的卡應該得到一樣的分數**，不論背後是不是 AAER 公司；若記憶滲入，同樣的卡上 AAER 公司會得較高分。

把 86 張卡依 (揭露紅旗數, 數字警訊數) 分組，13 組同時有 AAER 與對照（59 張卡）：
- 同一組內 AAER − 對照的加權平均分差：**+0.19 分**（滿分 100）
- 同組內分數標準差平均 1.2 分（評分幾乎是卡片內容的確定函數）
- 扣除組平均後的殘差 AUC：**0.51**（43 vs 43，等於隨機）

例：(5 紅旗, 1 警訊) 這組 7 家 AAER 都是 30–35 分，4 家對照都是 30 分；(3, 0) 這組 AAER 15–20、對照 15–20。

→ **AUC 0.71 完全來自卡片上的紅旗數，而不是模型認出公司。** 搭配第九輪 e 的結果（同一批 AAER 公司加上名稱後，分數與記憶的偏相關從 −0.09 跳到 +0.70），兩個方向都證實：拿掉身分 → 記憶進不來；加回身分 → 記憶立刻進來。

## 4. 敏感度與注意事項
- **規模懸殊的一對**：Super Micro（AAER）的同 SIC 對照只剩 Apple（資產 250 倍）。演算法依登錄規則在沒有 3 倍內同業時放寬。排除此對後合併 AUC **0.70（0.59–0.81）**，結論不變。
- **封閉式探針的策略**：兩個探針都說明它們是「把紅旗多的卡配給記憶中出過事的公司」。這是名單層級的記憶（知道哪些公司曾出事），不是卡片層級的辨識；實際命中 1/54，等於隨機。評分 agent 看不到任何名單，不受此影響。
- **AAER 年代**：9f 案例的 AAER 在 2017–2022 發布、模型訓練截止前，模型可能知道結果；正因如此，本輪檢驗的是「即使模型知道答案，輸入設計能不能讓它用不上」。
- LLM 分數（0.71）與直接數紅旗（0.69）幾乎相同：L3 設計下，LLM 的價值在**抽取並以引文驗證事實**，最後的判斷是把紅旗數轉成分數。
- 同一模型做抽取、評分、探針；第 3 節為事後分析。

## 5. 最終判定（第八輪 → 第九輪 f）

**目標一：讓 LLM 不知道是哪家公司、不知道後來有 AAER → 達成**

| | 4.02 時間外（27 對） | AAER 9d（16 對） | AAER 9f（27 對） |
|---|---|---|---|
| 給候選名單也配不對（L3 卡） | 1/54 | 0/32、2/32 | 1/54、1/54 |
| 評分者猜名稱 | 0/54 | 0/32 | 0/54 |
| 評分者知道後來出事 | 0/54 | 0/32 | 0/54 |

**目標二：分數來自推理還是記憶 → 來自推理（卡片內容），記憶貢獻不可偵測**

| 證據 | 結果 |
|---|---|
| 結果不可能被記得的樣本，仍有區分力 | 4.02 時間外 L3：0.76（0.62–0.88） |
| **模型記得結果的 AAER 樣本，在認不出公司時仍有區分力** | **合併 43 對 L3：0.71（0.60–0.81）** |
| 內容相同的卡，AAER 與對照分數相同 | 組內差 +0.19 分；殘差 AUC 0.51 |
| 控制內容後，無名稱分數與記憶無關；加名稱就有關 | 偏相關 −0.09 → +0.70 |
| 加上名稱，記憶立刻進來 | AUC 0.63 → 0.78；12/16 說出後來出事 |
