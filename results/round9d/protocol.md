# 第九輪 d：AAER 樣本上的類別計數卡（預先登錄）

本文件在建立任何 9d 卡片、執行任何 9d agent 之前提交。

## 0. 目的
- 9b 的 AAER 時間外樣本只有 3 對；9c 的 L2 卡在 4.02 樣本上通過封閉辨識（3/54），但只跑了一次、剛好在門檻上
- 本輪把 **L2 類別計數卡**套用到**所有已建好的 AAER 配對**，包括模型**記得結果**的截止前 AAER（第八輪：只給名稱 AUC 0.88）
- 這是目標一最嚴格的檢驗：模型**確實記得**這些公司後來有 AAER，L2 卡能否讓評分者無法知道是哪家公司，進而無法用上這個記憶

## 1. 樣本：16 對 AAER（32 張卡）
- 第八輪的 14 對（第七輪 AAER 清單；其中 13 家的 AAER 在模型截止前發布，Latch 在截止後）
- 9b 的 Travel + Leisure、The Bancorp 兩對（截止後 AAER）；9b 的 Latch 與第八輪是同一份 10-K，用第八輪那一對，不重複
- 事實：`results/round8/facts_verified.json`、`results/round9b/facts_verified.json`（已驗證，不重新抽取）
- 數字：`results/round7/financial_features.csv`、`results/round9b/financial_features.csv`
- L2 卡格式與 9c 完全相同（`round9c.l2_text`）；代碼重新隨機編為 A-01 至 A-32（種子 20261103），不保留原輪次前綴

## 2. 檢驗
| 代號 | 檢驗 | 標準 |
|---|---|---|
| D1 | 封閉式辨識：32 家名單 + 32 張 L2 卡，**兩個獨立 agent** | 兩次都 ≤ 3/32 |
| D2 | 第九輪 L2 封閉辨識**再跑兩次**（共三次） | 三次平均 ≤ 3/54 |
| D3 | J0-L2：L2 卡評分（不給名稱），自述知道後來有問題 | ≤ 1/32 |
| D4 | J0-L2 的 AUC（16 對） | 描述性 + 95% CI；與第八輪 J0（0.67）、MEM（0.88）比較 |
| D5 | J1-L2：同一張 L2 卡 + 真實名稱與年度；記憶效應指數（J1 − J0：問題組平均差 − 對照組平均差） | 描述性；預期截止前 AAER 為正（名稱喚起記憶），以此證明 J0-L2 擋住了記憶 |

判讀：
- D1、D2、D3 通過 → 在 AAER 標籤、而且模型**記得**結果的樣本上，評分輸入仍無法被辨識，評分者也不知道結果：目標一在 AAER 條件下成立
- D5 為正而 D3 通過 → 記憶存在、而且被 L2 卡擋住；J0-L2 的分數只能來自卡片內容（目標二）
- D1 或 D2 未通過 → 如實報告 L2 卡在該樣本上仍可辨識
