# 第九輪 d 結果：模型「記得」AAER 的樣本上，能不能把記憶擋住

> 設計見 [`protocol.md`](protocol.md)（主設計與兩次追加 9d-b、9d-c 都在執行對應 agent 前登錄）；程式輸出見 [`evaluation.md`](evaluation.md)。
> 樣本：**16 對 AAER**（32 份 10-K）。第八輪的 14 對（13 家 AAER 在模型截止前發布，Latch 在截止後）+ 9b 的 Travel + Leisure、The Bancorp。這是目標一最難的情況：模型**確實記得**多數問題公司後來出事。

## 一句話結論
- **記憶確實存在**：同一張卡加上公司名稱，評分者 13/32 說知道後來出事（其中 12 家是 AAER 公司），AUC 從 0.63 升到 0.78，記憶效應指數 +10.8（CI +4.9 至 +16.9）。
- **拿掉名稱，記憶就用不上**：L2、L3 卡的評分者 0/64 猜名稱、0/64 知道後來出事。
- **給候選名單的對抗辨識**：L2 卡在這個樣本上**未通過**（4–7/32），只剩紅旗總數的 **L3 卡通過**（0/32、2/32）。
- **在完全認不出公司的 L3 卡上，區分力只剩 AUC 0.62（CI 0.41–0.80），不顯著**；直接加總紅旗（不用 LLM）是 0.64。

## 1. 辨識：給 32 家名單，把卡配對回公司

| 卡片 | 內容 | 第一次 | 第二次 | 判定（≤ 3） |
|---|---|---|---|---|
| L2 | 7 個面向的紅旗計數 + 可計算項數 | 7/32 | 4/32 | ✗ |
| L2b | 同上，拿掉「可計算項數」（銀行線索） | 7/32 | 5/32 | ✗ |
| **L3** | **只有紅旗總數 + 數字訊號數** | **0/32** | **2/32** | **✓** |
| 參考：第九輪 4.02 樣本的 L2 | | 3/54、2/54、2/54（三次） | | ✓ |

- 第九輪的 4.02 樣本是一般人沒聽過的小型公司，L2 就夠了；**截止前的 AAER 公司**（GTT、CPI Aero、USA Technologies、Malvern、The Bancorp）模型對它們的「出事模式」有記憶，連面向計數都能部分對回去。
- 兩次都配對正確的多是同一批：GTT、The Bancorp、Malvern——正是模型最熟悉其會計問題的公司。**這本身就是記憶的證據**：探針靠的不是卡上的文字，而是「我記得這家公司有內控缺失 + 重編 + 調查」去對紅旗數量。
- 只剩總數時（L3），這條路被切斷：0/32、2/32，與隨機無異。

## 2. 評分：記憶的貢獻有多大

| 條件 | 評分者看到什麼 | AUC（16 對） | 95% CI | 自述知道後來出事 |
|---|---|---|---|---|
| J1-L2 | L2 卡 **+ 公司名稱** | **0.78** | 0.59–0.93 | 13/32 |
| J0-L2 | L2 卡 | 0.63 | 0.42–0.81 | 0/32 |
| J0-L3 | 只有紅旗總數 | 0.62 | 0.41–0.80 | 0/32 |
| 程式 | 紅旗總數 + 數字訊號數（不用 LLM） | 0.64 | 0.43–0.82 | – |
| 參考：第八輪 MEM | 只有名稱 | 0.88 | | |

- **名稱帶來 +0.15 AUC**（0.63 → 0.78），記憶效應指數 +10.8（只看截止前 13 對：+11.2），信賴區間都不含 0。這是「分數裡有多少是記憶」的直接量測。
- 拿掉名稱後，LLM 分數（0.62–0.63）和程式直接加總紅旗（0.64）幾乎一樣：**沒有名稱時，LLM 的判斷完全由卡片內容決定，而且沒有比數紅旗多出什麼。**
- 在這 16 對 AAER 上，不靠記憶的區分力**不顯著**（CI 下界 0.41–0.43）。對照第九輪 4.02 樣本（27 對，完全時間外）：AUC 0.77，顯著。差異可能來自樣本（AAER 案例多是年報裡看不出的舞弊，例如 GTT 的成本認列、SAExploration 的隱藏關係人交易）與樣本量。

## 3. 兩個目標的最終判定（第九輪全系列）

**目標一：讓 LLM 不知道是哪家公司、不知道後來有 AAER**

| 層次 | 截止後樣本（4.02 27 對 + AAER 3 對） | AAER 16 對（13 對截止前，模型記得結果） |
|---|---|---|
| 評分者不知道後來出事 | 0/114 ✓ | 0/64 ✓（加名稱時 12/16 知道 → 證明擋住的是真實存在的記憶） |
| 評分者認不出公司 | 開放式 0/60；猜名稱 0/114 ✓ | 猜名稱 0/64 ✓ |
| 給名單也認不出 | L2 卡 3、2、2/54 ✓ | **L3 卡 0、2/32 ✓**（L2、L2b ✗） |

→ **達成**，但對截止前、知名的 AAER 公司，要做到「給名單也認不出」，輸入必須粗化到只剩紅旗總數。

**目標二：分數來自推理還是記憶**

| 條件 | 結論 |
|---|---|
| 給名稱 | 分數**部分來自記憶**：+0.15 AUC、記憶效應 +10.8（CI 不含 0） |
| 不給名稱（L2／L3 卡） | 分數**完全來自卡片內容**：0/64 知道結果；LLM 分數 ≈ 程式數紅旗 |
| 不靠記憶的區分力 | 4.02 時間外 27 對：0.77（顯著）；AAER 16 對：0.62–0.64（不顯著） |

## 4. 對提案的意涵
1. **記憶污染是真實而且可量測的**：同一張卡，有沒有名稱差 0.15 AUC。任何 LLM 舞弊偵測的報告都應附上這個「名稱開關」。
2. **擋住記憶的代價是資訊**：完全認不出公司的輸入（L3）只剩紅旗總數，此時 LLM 不比數數多出什麼。
3. **實務建議**：評分輸入用 L2 類別計數卡（評分者不知道名稱、不知道結果，對一般公司給名單也認不出）；對知名公司的「對抗式」保證，搭配時間外樣本。效度評估一律用**截止後**事件。
4. 在 AAER 標籤上要得到顯著的乾淨估計，需要更多截止後 AAER（每 4 個月約 3 家，需要持續累積）。

## 5. 限制
- AAER 16 對，其中截止後只有 3 對；信賴區間寬
- 同一模型做抽取、評分、探針
- 9d-b、9d-c 是在 D1 未通過後追加的（皆先登錄再執行）；L3 是第四個嘗試的格式
