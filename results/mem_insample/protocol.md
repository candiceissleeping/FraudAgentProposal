# 時間內 4.02 樣本的隔離 MEM（預先登錄，2026-11-16）

本文件在選出任何公司、執行任何本實驗 session 之前提交。只用 Claude Opus 5.5。

## 0. 目的
實驗 B（`results/mem_isolated_oot/`）在訓練截止（2026-06）**之後**才申報 8-K Item 4.02 的 27 對公司上，只給名稱與年度，得到 AUC 0.69。
實驗 A（第八輪，0.88）的標籤是 AAER、公司也不同，兩者不能直接比較。
本實驗用**同一種標籤（8-K 4.02）、同一套選樣規則、同一份提示、同一個環境**，只把事件時間移到訓練截止**之前**，回答：

> 事件在模型訓練資料內（可能被記得）時，只給名稱的 AUC 比事件在訓練截止後（不可能被記得）時高多少？

## 1. 樣本
### 1.1 問題組
- 事件：**2023-01-01 至 2025-06-30** 申報的 8-K 或 8-K/A，ITEMS 含 4.02。距訓練截止至少一年，結果在訓練資料期間內已公開
- 每家公司取窗口內第一筆 4.02
- 排除（與第九輪相同）：SIC 6770（空白支票／SPAC）、沒有 SIC、4.02 申報日之前少於兩份原始 10-K、Y0 10-K 沒有 XBRL
- 另外排除：實驗 A（第八輪 28 家）與實驗 B（時間外 54 家）用過的公司，讓樣本互不重疊
- Y0：4.02 申報日之前最後一份**原始** 10-K；會計年度＝Y0 的期末日
- 從合格者以種子 20261116 隨機抽 **54 家**

### 1.2 對照組（每家問題公司 1 家，程式選）
- 候選池：SEC XBRL frames（`us-gaap:Assets`，2021Q1–2025Q4 各季）出現過的公司，扣除問題組、實驗 A／B 的公司、SIC 6770
- **候選必須自 2021-01-01 至今沒有任何 8-K 4.02**（依 data.sec.gov submissions）。這比第九輪嚴格（第九輪只排除窗口內的 4.02）：時間內的對照若之後重編，就是標錯的陽性。為了可比，第 4 節對實驗 B 做同規則的敏感度分析
- 必須有期末日在問題公司 Y0 期末 ±92 天內的原始 10-K（含 XBRL），且之前還有一份原始 10-K
- 同產業：先 4 位 SIC；該層級最接近者的規模比 > 3 倍或沒有候選，就放寬到 3 位、再到 2 位；三層都沒有 ≤ 3 倍者，取 4 位層級中最接近者並標示
- 規模：與問題公司 Y0 期末同一日曆季的 frames 總資產，取 |ln(對照 ÷ 問題)| 最小者
- 依隨機順序處理問題公司；每家對照只用一次；找不到對照的問題公司剔除並記錄

### 1.3 名稱
- 用 Y0 期末當時的公司名稱（依 submissions 的 formerNames；沒有就用目前名稱）
- 同一個程式統一格式：全大寫的名稱轉為字首大寫；拿掉 `/DE/` 這類州別標記；Inc／Corp／Ltd／Co 補句點。問題組與對照組用同一規則，並報告兩組原始名稱為全大寫的比例

## 2. 輸入與執行
- 108 家公司，以配對為單位隨機分成兩份名單（A、B 各 27 對、54 家），長度與實驗 B 相同
- 提示：`data/mem_insample/prompt.md`，與實驗 B 的 `data/mem_isolated_oot/prompt.md` 逐字相同
- 每份名單 5 次，每次以不同種子打亂順序；共 10 次
- 環境與實驗 A／B 相同：`experiment/mem_isolated.py run`（`claude -p --tools "" --strict-mcp-config --setting-sources "" --no-session-persistence`，新的空目錄，每次 7 項無上網檢查）
- 原始紀錄 commit 之後才讀標籤

## 3. 指標
1. **主要**：54 對、5 次平均分數的 AUC，配對 bootstrap 95% CI，組內勝／平／負
2. **與實驗 B 的差**：AUC 差與 bootstrap 95% CI（兩樣本各自重抽）；每對分數差（問題 − 對照）平均值的差與 CI
3. 問題組、對照組說「知道後來出事」的比例；只用「知道」旗標的 AUC
4. 依「問題公司 5 次中 ≥ 3 次說知道」分組，各組的配對分數差

## 4. 敏感度分析
- 實驗 B 排除「對照公司自 2021 年起曾申報 4.02」的配對後重算 AUC，與本實驗同規則比較
- 本實驗只用名單 A、只用名單 B 各自的 AUC

## 5. 判讀（事先寫下）
| 結果 | 判讀 |
|---|---|
| 本實驗 AUC 明顯高於 0.69（差的 CI 下界 > 0），且問題組說「知道」的比例高 | 同一種標籤下，記得結果使只給名稱的分數上升；支持「高分來自記憶」 |
| 本實驗 AUC 與 0.69 相近（差的 CI 含 0），問題組多數說「不知道」 | 模型對多數 4.02 事件沒有記憶；0.88 與 0.69 的差主要來自標籤（AAER 對 4.02）與公司知名度，不是記憶本身 |
| AUC 相近，但問題組說「知道」比例高 | 記得但沒有反映在分數上，需要逐家檢查 |

## 6. 限制（事先寫下）
- 4.02 多為會計錯誤，不全是舞弊
- 對照組的 4.02 排除規則比第九輪嚴格（見 1.2、第 4 節）
- submissions 只讀 recent 區塊（最近約 1000 筆申報）；申報極多的公司可能漏看 2021 年的 4.02
- 只用 Opus 5.5；effort 用 CLI 預設值
