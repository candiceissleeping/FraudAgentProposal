# 講稿大綱：LLM 的記憶與刻板印象（5 分鐘）

粗體的「講」和它下面的條列是可以直接照念的內容。每段標的秒數是建議分配。

## 0. 開場：我的問題（30 秒）

**講**：我的實驗是讓 LLM 讀 10-K，替公司打舞弊風險分數。問題是，模型早就知道 Enron、WorldCom 後來出事。它給高分，是從文件讀出來的，還是它本來就記得？我自己第四輪把公司名稱遮掉之後，72 份文件裡還是有 62 份被模型認出來。所以我回頭去整理文獻：記憶怎麼定義、怎麼證明、怎麼解決。

## 1. 記憶怎麼定義（55 秒）

**講**：記憶沒有單一定義，但可以分成兩種。

- 一種是「背原文」：給開頭就能逐字接下去。來源是 Carlini 等人（2021，USENIX Security）。
- 另一種是「知道結果」：不必背得出原文，但知道後來發生什麼事。

**講**：我關心第二種。在我的實驗裡它有兩種形式。一種是具體的事實，模型知道 Enron 後來倒了，這影響我的問題公司。另一種是籠統的印象，文獻叫實體偏誤，Lee 等人發現證據完全對等時，模型仍偏好大型股和科技股，這影響我的對照組。還有一個限制：目前無法分辨答案來自記憶還是推理，所以測到有記憶是定論，測不到只是下界。

## 2. 怎麼證明（45 秒）

**講**：證明的邏輯是文件固定，只改身分線索，看結果變不變。我分兩層看。

- 第一層，模型認不認得出來。Lopez-Lira 等人把法說會遮蔽後請 GPT-4o 猜，Apple、Meta、Microsoft 全部猜中；大型公司六成六，小型公司三成。我第四輪的結果是同樣的現象。
- 第二層，認得出來之後分數會不會變。Nakagawa 等人發現，同一段文字只是加上公司名，就有一到兩成的案例分數改變。

**講**：另外，Karvonen 與 Marks 發現偏誤不會出現在推理文字裡，所以不能靠讀模型的解釋來檢查。

## 3. 怎麼解決（110 秒）

**講**：先講三個已被證明無效的做法。

- 叫模型假裝不知道：Lopez-Lira 等人給模型假的截止日，前後準確率幾乎一樣。
- 只遮公司名：Engelberg 等人發現仍有 69% 被認出。
- 讓模型遺忘：Zhang 等人發現把模型壓縮一下，忘掉的知識就從 21% 回到 83%。

**講**：有效但有代價的有兩種。

- 時間截斷模型：只用某個日期之前的資料訓練。唯一保證沒有記憶，但模型太小，讀不完一份 10-K。
- 反覆遮蔽加改寫，直到另一個模型認不出來。Engelberg 等人在 50 萬篇新聞上把辨識率降到 0.11%。但它連數字也遮掉，而且只在情緒分析上驗證過。

**講**：2026 年有一個很新的做法，是直接調整模型內部。Merchant 與 Levy 在模型裡找到一個「時間意識」的特徵。他們問模型：現在是 2018 年 1 月，Newmont 礦業接下來會收購誰？原本模型直接說出 Goldcorp，因為它記得 2019 年真的收購了。把時間意識調強之後，模型自己說不能用事後才知道的事，改從 2018 年的情勢去推，Goldcorp 就不在答案裡了。

**講**：整體趨勢是不再宣稱消除記憶，而是報告它最多影響多少。目前最站得住的是兩種合用：強模型加遮蔽當主要結果，時間截斷模型當對照。

## 4. 缺口與我的實驗（50 秒）

**講**：文獻有三個缺口，剛好是我的題目。

- 沒有人在舞弊偵測上驗證過這些方法。
- 沒有人測過完整的 10-K。
- 遮蔽會把數字遮掉，但舞弊判斷可能正需要數字，這個代價沒有人量過。

**講**：我下一步是把同一批 10-K 做成原文、只遮名字、完整遮蔽三個版本，再加一個保留數字的版本，比較問題公司和對照公司的分數差距。另外用時間截斷模型當對照。如果完整遮蔽後差距消失，代表原本的偵測能力主要來自記憶；如果差距還在，才是模型真的讀出問題的證據。

## 5. 結尾（10 秒）

**講**：總結一句：記憶可以被證明存在，但目前沒有方法能證明它已經被消除。我的實驗要回答的是，在舞弊偵測上，去掉記憶之後還剩多少。

## 老師可能會問

**Merchant 與 Levy 那個做法，你可以用嗎？**
目前不行，有四個限制。它要能改模型內部，只能用在開源模型上（他們用 Gemma 3 和 Qwen）。他們找到五個候選特徵，測試後只有一個真的有效。作者自己說這不是完整的解法，調太強會傷到模型的一般能力。它是預印本，而且測的是「模型有沒有說出未來才知道的名字」，比舞弊評分容易判斷。

**為什麼不直接用訓練截止日之後的案例？**
這是最乾淨的做法，但舞弊通常要好幾年才被證實，近期案例少、標籤也不確定。這是我的判斷，文獻沒有直接討論。

**時間截斷模型不能用嗎？**
ChronoGPT 有 1999 到 2024 的年度版本，涵蓋 Enron 和 WorldCom，但一次只能讀 1,792 個字詞。可以對分段評分，當作保證沒有記憶的對照組，不適合當主要模型。

**遮蔽後認不出來，就代表沒有記憶了嗎？**
不代表。有研究發現模型輸出看起來公平，內部卻仍保留身分資訊。所以遮蔽之後還要做名稱對調的測試。

**記憶一定會讓分數虛高嗎？**
不一定。Glasserman 與 Lin 發現遮掉公司名後表現反而變好，大公司尤其明顯。他們稱為分心效應：模型對公司的印象會干擾它讀文字。所以偏誤的方向不固定。

**記憶的影響有多大？**
Engelberg 等人把原文和遮蔽版的預測力差距當作上界。預測次日報酬時，新聞最多 12–36%，年報的 MD&A 段落最多 41–45%。長文件的問題可能更嚴重。

**越有名的公司越嚴重嗎？**
是。除了 Lopez-Lira 等人的大小型公司落差，Xie 等人發現最熱門的問題上，GPT-4 有 80% 堅持自己記得的答案。

**這些文獻可靠嗎？**
我引用的關鍵數字都對照過論文原文。要說明的是，Lopez-Lira、Engelberg、He 這幾篇財金的關鍵文獻還是工作論文，Merchant 與 Levy、Karvonen 與 Marks 是預印本。有經過同儕審查的是 Carlini、Nakagawa、Lee、Zhang 這幾篇。

**為什麼 unlearning 不行？**
除了可以復原之外，舞弊警訊的知識有一部分本來就是從 Enron、WorldCom 來的，忘得乾淨會連判斷能力一起削掉。這一點是我的推論。

**「知道結果」這種記憶是誰定義的？**
分成兩種是我的歸納。最接近的出處是 Ludwig、Mullainathan 與 Rambachan，他們要求訓練資料和研究樣本之間不能有洩漏，並明講逐字重現不是洩漏的必要條件。
