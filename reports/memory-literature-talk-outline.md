# 講稿大綱：LLM 的記憶與刻板印象（5 分鐘）

粗體的「講」是可以直接照念的句子，全部念完約 1,000 字，正常語速約 5 分鐘。每段標的秒數是建議分配。

## 0. 開場：我的問題（30 秒）

**講**：我的實驗是讓 LLM 讀 10-K，替公司打舞弊風險分數。問題是，模型早就知道 Enron、WorldCom 後來出事。它給高分，是從文件讀出來的，還是它本來就記得？我自己第四輪把公司名稱遮掉之後，72 份文件裡還是有 62 份被模型認出來。所以我回頭去整理文獻：記憶怎麼定義、怎麼證明、怎麼解決。

## 1. 記憶怎麼定義（45 秒）

**講**：文獻沒有單一定義，不同領域用不同的詞。

- 隱私領域叫 memorization，指模型能把訓練資料逐字背出來。
- 評測領域叫資料污染，指考題出現在訓練資料裡。
- 財金領域叫 look-ahead bias，指模型的訓練資料包含預測時點之後的資訊，不需要逐字重現也算。

**講**：我的情況最接近財金的定義。我擔心的不是模型背得出 10-K 原文，而是它知道這家公司後來的下場。另外有一個根本限制：目前沒辦法逐例分辨模型的答案來自記憶還是推理。所以測到有記憶是定論，測不到只是下界。

## 2. 怎麼證明（45 秒）

**講**：證明的邏輯只有一條：文件固定，只改身分線索，看結果變不變。常見的做法有三種。

- 只給公司名和日期，不給文件，看模型答不答得出來。
- 同一段文字，加上公司名和不加，比較分數。Nakagawa 等人發現約一到兩成的案例分數會變。
- 遮掉名字後請模型猜是哪家公司。Lopez-Lira 等人發現 Apple、Meta、Microsoft 百分之百被認出。

## 3. 刻板印象（30 秒）

**講**：刻板印象在文獻裡叫實體偏誤，指模型的判斷來自它對這個名字的既有印象。有兩個重點。第一，越有名的實體越嚴重，Xie 等人發現最熱門的問題上，GPT-4 有八成堅持自己記得的答案。第二，偏誤不會出現在模型的推理文字裡，所以不能靠讀它的解釋來檢查。

## 4. 怎麼解決（80 秒）

**講**：先講三個已經被證明無效的做法。

- 叫模型假裝不知道：Lopez-Lira 等人給模型一個假的知識截止日，截止日前後的準確率幾乎一樣，97.6% 對 98.0%。
- 只遮公司名：Engelberg 等人發現仍有 69% 被認出，和我第四輪的結果一致。
- 讓模型遺忘，也就是 machine unlearning：忘掉的知識有 88% 可以復原，只是被藏起來。

**講**：目前比較有效的有兩種，各有代價。

- 第一種是時間截斷模型，只用某個日期之前的資料訓練。這是唯一保證沒有記憶的做法，但模型很小，讀不完整份 10-K。
- 第二種是反覆遮蔽加改寫，直到另一個模型認不出來。Engelberg 等人在 50 萬篇新聞上把辨識率降到 0.11%，和隨機猜測一樣。但它會把數字也遮掉，而且只在情緒分析上驗證過。

**講**：2026 年的新方向是在模型作答時扣掉記憶的成分，或是直接調整模型內部。整體趨勢是不再宣稱消除記憶，而是報告記憶最多影響多少。

## 5. 缺口與我的實驗（60 秒）

**講**：文獻有三個缺口，剛好是我的題目。

- 沒有人在舞弊偵測上驗證過這些方法，現有證據都來自情緒分析和報酬預測。
- 沒有人測過完整的 10-K。
- 遮蔽會把數字遮掉，但舞弊判斷可能正需要數字，這個代價沒有人量過。

**講**：所以我下一步打算這樣做。同一批 10-K 做三個版本：原文、只遮名字、完整遮蔽，再加一個保留數字的版本，比較問題公司和對照公司的分數差距怎麼變。另外用時間截斷模型當對照組。如果完整遮蔽後差距消失，代表原本的偵測能力主要來自記憶；如果差距還在，才是模型真的讀出問題的證據。兩種結果都有意義。

## 6. 結尾（10 秒）

**講**：總結一句：記憶可以被證明存在，但目前沒有方法能證明它已經被消除。我的實驗要回答的是，在舞弊偵測上，去掉記憶之後還剩多少。

## 老師可能會問

**為什麼不直接用訓練截止日之後的案例？**
這是最乾淨的做法，但舞弊通常要好幾年才被證實，近期案例少、標籤也不確定。這是我的判斷，文獻沒有直接討論。

**時間截斷模型不能用嗎？**
ChronoGPT 有 1999 到 2024 的年度版本，涵蓋 Enron 和 WorldCom，但一次只能讀一千多個字詞。可以對分段評分，當作保證沒有記憶的對照組，不適合當主要模型。

**遮蔽後認不出來，就代表沒有記憶了嗎？**
不代表。有研究發現模型輸出看起來公平，內部卻仍保留身分資訊。所以遮蔽之後還要做名稱對調的測試。

**這些文獻可靠嗎？**
我引用的關鍵數字都對照過論文全文。要說明的是，Lopez-Lira、Engelberg、Wu 這幾篇財金的關鍵文獻還是工作論文，沒有經過同儕審查。

**為什麼 unlearning 不行？**
除了可以復原之外，舞弊警訊的知識有一部分本來就是從 Enron、WorldCom 來的，忘得乾淨會連判斷能力一起削掉。這一點是我的推論。
